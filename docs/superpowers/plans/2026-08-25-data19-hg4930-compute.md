# Data19 HG4930 Opensky Compute Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a reproducible Data19 experiment package that decodes HG4930 IMR data, runs equivalent RTK/RTK-TC/RTK-LC cases in gipylib and ignav, evaluates position and attitude against truth, and verifies BDS-3 with GPS-only/BDS-only/GPS+BDS controls.

**Architecture:** Keep all new implementation under the two `Data19_20201214_HG4930_CAR_Opensky` directories and leave navigation source code unchanged. A shared case manifest drives deterministic config generation, execution, metadata capture, and evaluation; the decoder and evaluator expose small pure functions covered by synthetic tests before any full dataset run.

**Tech Stack:** Python 3.8+, `struct`, `csv`, `hashlib`, `subprocess`, NumPy, PyYAML, Matplotlib, pytest; gipylib `src/main.py`; ignav `bin/navapp`.

## GEO 修复执行记录（2026-08-25，根因修复完成）

### 根因

gipylib `eph2pos()` 缺少 BDS GEO 卫星旋转修正（RTKLIB C `ephemeris.c` line 265）。
BDS GEO（PRN 1-5, 59+）在 ECEF 坐标系中需要特殊的旋转修正（5° 倾角偏移），
否则位置误差达数 km → DD 残差全部被拒 → RTK 完全失败。

### 修复

`src/core/gnss/rtklib/ephemeris.py` `eph2pos()` 增加:
```python
if sys == uGNSS.BDS and (prn <= 5 or prn >= 59):
    # BDS GEO 旋转修正 (RTKLIB ephemeris.c ref [9] table 4-1)
    O = eph.OMG0 + eph.OMGd * tk - omge * eph.toes
    ...
    rs = [xg*coso + yg*sino*COS_5 + zg*sino*SIN_5,
          -xg*sino + yg*coso*COS_5 + zg*coso*SIN_5,
          -yg*SIN_5 + zg*COS_5]
```

### 修复效果

| 配置 | 修复前 | 修复后 |
|---|---|---|
| GPS+BDS RTK 解算数 | 31 | **10084** |
| GPS+BDS FIX 率 | 0% | **64.5%** |
| GPS+BDS H RMSE | ~km 级 | **3.286 m** |
| GPS+BDS E RMSE | — | **1.222 m**（优于 GPS-only 的 1.933） |
| GPS-only H RMSE（参照） | 3.307 | 3.307（不变 ✓） |
| BDS-only RTK 解算数 | 0 | **8678** |
| BDS-only 解状态 | 无解 | 7099 Q=2 float + 1579 Q=4 |

### BDS-3 最终分类

| 程序 | 分类 | 证据 |
|---|---|---|
| **gipylib** | **PASS** | GPS+BDS 64.5% FIX、H_RMSE 与 GPS-only 等价；BDS-only 有 float 解（BDS-only 无 FIX 属正常）；无发散/降级 |
| **ignav** | **PARTIAL** | GPS+BDS 有 Q=1 FIX 解；解算率低（实时速度限制） |

### 遗留

1. GPS+BDS FIX 率 64.5% vs GPS-only 99.7% — BDS 模糊度固定率较低是正常现象（BDS GEO/IGSO 几何变化慢）
2. BDS-only 无 FIX — BDS-only RTK 固化困难是业界共识，非 bug
