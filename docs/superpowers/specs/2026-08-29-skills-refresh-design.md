# Skills 文档状态刷新设计

## 目标

根据 `issue/` 目录中的全部 13 个 issue，将 `skills/` 下 16 个文档更新到截至 2026-08-29 的项目状态，同时保留实验历史和设计依据。

## 方案

新增 `skills/项目当前状态.md` 作为唯一的现状索引，集中记录架构、GNSS/BDS、TC/LC、初始化、机械编排、输出、手机 RTD-TC 和验证纪律。每个现有 skill 文件顶部加入短索引，说明本文的适用范围、当前实现入口和必须服从的权威状态页。历史章节不删除；与状态页冲突的旧实验结论标记为历史背景，不作为当前配置依据。

## 内容边界

- 不修改 `src/`、`data/`、`phone/`、测试、输出结果或用户已有工作区修改。
- 不把实验候选值误写成通用默认值；明确 TC/LC 和数据集边界。
- 明确当前通过基线、已验证修复、未完成事项、请示停点和回退纪律。
- 修正 `GInsStream.md`、`imu.md` 等文档中会误导后续开发的明显过期架构/插值表述。

## 验收

- 16 个现有 skill 文件均包含状态索引。
- 状态页覆盖所有 issue 的最终结论与遗留项。
- `rg` 检查不存在状态页中明确禁止的“当前仍为双滤波”“TC AR 未修复”等误导性现状表述。
- Git diff 仅包含本次文档刷新新增/修改内容，不覆盖既有用户修改。
