# 紧组合分离增量式数据和速率式数据结算 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在紧组合（TC）链路中明确区分 `RateImuData` 与 `IncrementImuData`，让 GREAT-MSF campus01 的原始 100 Hz 速率 IMU 既能直接机械编排，也能严格流式地转成增量后复用现有 ECEF `InsUpdate` 机械编排，并以 GREAT-MSF 全频率基线、10 Hz 真值侧最近邻精度和原始 100 Hz 平面轨迹完成可复现实验对比。

**Architecture:** 保留 `src/core/data_types.py` 已有两种 IMU 类型作为唯一数据模型，TC 只增加按类型分派的编排层，不复制新的“临时增量”结构。速率转增量及 GNSS 边界处理复用 LC/KF-GINS 已验证的严格流式 previous/current 模式与 `split_increment_at_gnss`：前段时间差 `< 1 ms` 不切、后段 `<= 1 ms` 不留，并让 `InsUpdate.update` 统一执行 ECEF 机械编排；估计器的状态转移和噪声离散化必须使用与机械编排相同的有效 `dt`。实验层把 GREAT-MSF、gipylib rate、gipylib rate→increment 三条管线分开落盘；评估从每个 10 Hz truth 历元寻找时间窗内最近结果，不插值真值，绘图直接读取两个 gipylib 100 Hz 状态文件。

**Tech Stack:** Python 3、NumPy、pytest、PyYAML、Matplotlib、现有 gipylib ECEF INS/TC 组件、CMake、C++ GREAT-MSF、GLFW、OpenGL。

- [ ] **Step 6: 后备路径 B——仅当系统包不可用时，用 CMake FetchContent 固定 GLFW 版本**

路径优先级是 A 后 B：只要 apt/系统 `find_package` 成功，就不启用 B。只有仓库源中没有 `libglfw3-dev`、安装权限受限或系统包无法被 CMake 识别时，才把非 Windows 分支替换为以下实现；GLFW 固定为 `3.4`，关闭其示例、测试和文档构建，OpenGL 继续使用平台正式实现：

```cmake
if(WIN32)
    target_link_libraries(${PROJECT_NAME} PRIVATE glfw3 opengl32)
else()
    find_package(OpenGL REQUIRED)
    find_package(glfw3 3.3 CONFIG QUIET)

    option(GREAT_FETCH_GLFW "Fetch pinned GLFW when no system package is available" OFF)
    if(NOT TARGET glfw)
        if(NOT GREAT_FETCH_GLFW)
            message(FATAL_ERROR
                "GLFW >= 3.3 was not found; install libglfw3-dev or configure with -DGREAT_FETCH_GLFW=ON")
        endif()
        include(FetchContent)
        set(GLFW_BUILD_EXAMPLES OFF CACHE BOOL "" FORCE)
        set(GLFW_BUILD_TESTS OFF CACHE BOOL "" FORCE)
        set(GLFW_BUILD_DOCS OFF CACHE BOOL "" FORCE)
        FetchContent_Declare(
            glfw
            GIT_REPOSITORY https://github.com/glfw/glfw.git
            GIT_TAG 3.4
            GIT_SHALLOW TRUE
        )
        FetchContent_MakeAvailable(glfw)
    endif()
    target_link_libraries(${PROJECT_NAME} PRIVATE glfw OpenGL::GL)
endif()
```

```python
def nearest_results_for_truth(truth_sow, result_sow, max_dt=0.051):
    right = np.searchsorted(result_sow, truth_sow, side="left")
    left = np.clip(right - 1, 0, len(result_sow) - 1)
    right = np.clip(right, 0, len(result_sow) - 1)
    choose_left = np.abs(truth_sow - result_sow[left]) <= np.abs(result_sow[right] - truth_sow)
    selected = np.where(choose_left, left, right)
    delta = np.abs(result_sow[selected] - truth_sow)
    selected[delta > max_dt] = -1
    return Match(selected, delta, matched_count=np.count_nonzero(selected >= 0),
                 total_truth_count=len(truth_sow))
```

空 result 必须返回全 `-1`，不让 `np.clip` 访问空数组；重复或逆序时间直接报错。
