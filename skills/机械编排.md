## 1. 概述

### 1.1 设计目标

INS 机械编排是组合导航的"预测"阶段，承接 [初始化.md](file:///home/mxl/workplace/gipylib/skills/初始化.md) 装配的 `InsState`，对源源不断的 IMU 数据执行 E 系下的姿态/速度/位置递推，并在 GNSS 历元到达时联动执行量测更新，完成松组合 EKF 的预测-更新闭环。

**核心要求**（用户原话）：
1. **承接初始化**：当初始化完成后，对输入的 IMU 数据进行机械编排
2. **源代码位置**：相应的源代码应该放在 `src/core/imu/`（**实际实现时统一放在 `src/core/ins/`**，与初始化模块共用，详见第 2.3 节）
3. **联动 GNSS 量测更新**：机械编排过程中要做好衔接规划，后续要联动 GNSS 数据进行量测更新工作

**机械编排的核心任务**：
1. **预测（Time Update）**：利用 IMU 比力/角速度递推 INS 状态（姿态、速度、位置），同时传播 EKF 误差协方差 P
2. **量测更新触发判定**：根据 GNSS 历元时间戳，决定何时触发量测更新（4 种时间对齐情况）
3. **量测更新衔接**：在 GNSS 历元时刻提供 INS 预测状态，供 EKF 执行量测更新
4. **状态反馈**：将 EKF 估计的误差状态反馈到 INS 全状态

## 3. 机械编排的触发与输入输出

### 3.1 触发条件

机械编排主循环由 `LcIntegration` 驱动（详见 [estimator.md 第 6 节](file:///home/mxl/workplace/gipylib/skills/estimator.md#6-时间对齐策略)），从 `estimate_queue` 消费 `AlignedBlock`。机械编排触发的条件：

1. **初始化已完成**：`InsInitializer` 已输出有效的 `InsState + P`，状态机切换到 `INITIALIZED`
2. **IMU 数据已就绪**：`AlignedBlock.imu_list` 至少包含 1 个 `ImuMeasurement`
3. **imupre / imucur 配对**：前一个 IMU 历元 `imupre` 已保存（首次机械编排的特殊处理见第 10 节）

### 3.2 输入数据

| 数据 | 字段 | 来源 | 说明 |
|------|------|------|------|
| INS 当前状态 | `InsState` | `InsInitializer.initialize()` 输出 / 上一次机械编排结果 | 含 `timestamp`、`pos_e`、`vel_e`、`C_b_e`、`q_b_e`、`gyro_bias`、`accel_bias` 等 |
| 协方差矩阵 | `P` (NxN) | `InsInitializer` 装配 / 上一次反馈后 | N = `StateIndex.dim`（15~24 维），统一管理所有误差状态 |
| 当前 IMU 历元 | `imucur: ImuMeasurement` | `AlignedBlock.imu_list` | `timestamp`、`gyro`、`accel` |
| 前一 IMU 历元 | `imupre: ImuMeasurement` | 内部保存 | `timestamp`、`gyro`、`accel` |
| GNSS 解（可选） | `gnss: GnssSolution` | `AlignedBlock.gnss` | 可能为 `None`（非 GNSS 历元） |

### 3.3 输出数据

| 数据 | 字段 | 去向 | 说明 |
|------|------|------|------|
| 预测后 INS 状态 | `InsState` | `LcIntegration` 量测更新 / 输出 | 含更新后的姿态/速度/位置 |
| 状态转移矩阵 | `Φ` (NxN) | `LcIntegration` 时间更新 | 离散化状态转移矩阵 |
| 过程噪声矩阵 | `Q` (NxN) | `LcIntegration` 时间更新 | 离散化过程噪声 |
| 量测更新触发标志 | `trigger_gnss_update: bool` | `LcIntegration` | 是否在本历元执行 GNSS 量测更新 |
| 量测残差（若触发） | `y = z - H*x` | `LcIntegration` 量测更新 | GNSS 位置/速度残差 |

### 3.4 机械编排的输入输出时序

```
AlignedBlock_i 到达:
  imu_list = [imu_1, imu_2, ..., imu_K]   (K 个 IMU 历元)
  gnss = GnssSolution or None             (1 个 GNSS 历元，可能为 None)

机械编排循环 (for imu in imu_list):
  ┌─────────────────────────────────────┐
  │ imupre, imucur = imupre, imu        │
  │ 1. imu_compensate(imucur, state)    │  ← 第 4 节
  │ 2. dt = imucur.ts - imupre.ts       │
  │ 3. InsCore.update(imucur, dt)       │  ← 第 5 节（姿态/速度/位置递推）
  │ 4. TransferMatrix.build_F(state, dt)│  ← 第 6 节
  │ 5. Φ = I + F*dt (一阶)              │
  │ 6. Q = build_Q(dt)                  │
  │ 7. 检查 GNSS 时间对齐 (4 种情况)    │  ← 第 7.4 节
  │ 8. 若触发量测更新: 计算 H, z, R     │  ← 第 7 节
  └─────────────────────────────────────┘
  ↓ 输出: 预测状态 + (Φ, Q) + (可选)量测残差
```

## 4. IMU 误差补偿

### 4.1 补偿内容

参考 KF-GINS `gi_engine.cpp::imuCompensate`（行 50-70），IMU 误差补偿在机械编排**之前**执行，对原始 IMU 测量值进行修正：

```
function imu_compensate(imu, state):
  # 1. 陀螺零偏补偿
  omega_corrected = imu.gyro - state.gyro_bias

  # 2. 加计零偏补偿
  f_corrected = imu.accel - state.accel_bias

  # 3. 杆臂补偿（若 IMU 与 GNSS 天线不重合）
  #    杆臂效应加速度: a_leverarm = ω × (ω × r) + α × r
  if any(state.leverarm != 0):
    r_lever = state.leverarm  # b 系杆臂
    omega = omega_corrected
    alpha = (omega - prev_omega) / dt  # 角加速度
    a_leverarm = cross(omega, cross(omega, r_lever)) + cross(alpha, r_lever)
    f_corrected = f_corrected - a_leverarm

  imu.gyro = omega_corrected
  imu.accel = f_corrected
  return imu
```

### 4.2 补偿顺序

参考 KF-GINS 的补偿顺序：
1. **零偏补偿**（最基本，必做）
2. **杆臂效应补偿**（可选，`leverarm != 0` 时启用）

### 4.3 与 KF-GINS 的差异

| 维度 | KF-GINS | 本项目 |
|------|---------|--------|
| IMU 数据形式 | 增量 (dtheta/dvel) | 速率 (gyro/accel) |
| 补偿对象 | dtheta -= bias*dt; dvel -= bias*dt | gyro -= bias; accel -= bias |
| 杆臂补偿 | 在 insMech 内部处理 | 在 imu_compensate 中预处理 |
| 调用时机 | `addImuData(imu, compensate=true)` 时调用 | `ImuMechanizer.process_epoch` 入口处调用 |

## 5. 机械编排方程（E 系下）

> 详细方程与推导详见 [imu.md 第 6 节](file:///home/mxl/workplace/gipylib/skills/imu.md#6-ins-机械编排)。本节仅给出工作流程概要。

### 5.1 姿态更新

```
E 系下姿态更新:

  C_b^e(k+1) = C_b^e(k) * ΔC_b(k→k+1)

计算步骤:
  1. E 系地球自转在 b 系投影:
     ω_ie_b = (C_b^e)^T * [0, 0, ω_e]^T

  2. b 系相对 e 系角速度:
     ω_eb_b = ω_ib_b - ω_ie_b    （ω_ib_b 为补偿后的陀螺输出）

  3. 旋转矢量:
     φ = ω_eb_b * dt

  4. 构造旋转矩阵（Rodrigues 公式）:
     |φ| < ε:  ΔC = I + [φ×]
     |φ| ≥ ε:  ΔC = I + sin(|φ|)/|φ| * [φ×] + (1-cos(|φ|))/|φ|² * [φ×]²

  5. 姿态更新:
     C_b^e(k+1) = C_b^e(k) * ΔC

  6. 正交化（SVD 分解，防止数值漂移）:
     C_b^e(k+1) = U * V^T
```

### 5.2 速度更新

```
E 系下速度更新:

  v^e(k+1) = v^e(k) + (f^e - 2*ω_ie^e × v^e + g^e) * dt

计算步骤:
  1. 比力在 E 系投影:
     f^e = C_b^e(k+1) * f_b_corrected    （使用更新后的姿态）

  2. E 系地球自转（常数）:
     ω_ie^e = [0, 0, ω_e]^T    ω_e = 7.2921151467e-5 rad/s

  3. E 系名义重力（位置函数）:
     g^e = gravity_ecef_normal(r^e)
     # 对齐 ignav updateins() 的普通 gravity()，仅用于名义速度积分。
     # TransferMatrix 的重力梯度继续使用 gravity_ecef(r^e)，后者对齐 pregrav()。

  4. Coriolis 加速度:
     a_coriolis = -2 * skew(ω_ie^e) @ v^e(k)

  5. 速度更新:
     v^e(k+1) = v^e(k) + (f^e + a_coriolis + g^e) * dt
```

### 5.3 位置更新

```
E 系下位置更新:

  r^e(k+1) = r^e(k) + v^e(k+1) * dt

注: 使用更新后的速度 v^e(k+1)（隐式一阶欧拉法），参考 KF-GINS insmech.cpp。
```

### 5.4 完整递推流程（InsCore.update）

参考 [imu.md 第 6.5 节](file:///home/mxl/workplace/gipylib/skills/imu.md#65-完整递推流程inscoreupdate)，`InsCore.update(imu, dt)` 的完整流程：

```
InsCore.update(imu, dt):

  # 输入: imu (已补偿), dt (由相邻 timestamp 计算)
  # 状态: state (含 pos_e, vel_e, C_b_e, gyro_bias, accel_bias 等)

  1. 姿态更新（第 5.1 节）
     C_be_new = attitude_update(state.C_b_e, imu.gyro, dt)

  2. 速度更新（第 5.2 节）
     v_e_new = velocity_update(state.vel_e, imu.accel, C_be_new, state.pos_e, dt)

  3. 位置更新（第 5.3 节）
     r_e_new = position_update(state.pos_e, v_e_new, dt)

  4. 装配新状态
     state_new = InsState(
       timestamp = imu.timestamp,
       pos_e = r_e_new,
       vel_e = v_e_new,
       C_b_e = C_be_new,
       q_b_e = dcm2quat(C_be_new),
       att_rpy = dcm2euler(C_be_new @ C_e_n),
       gyro_bias = state.gyro_bias,       # 零偏由 EKF 反馈更新
       accel_bias = state.accel_bias,
       imu_angle = state.imu_angle,
       imu_leverarm = state.imu_leverarm,
       leverarm = state.leverarm,
     )

  return state_new
```

### 6.2 离散化 Φ

```
连续时间 F 矩阵 → 离散时间 Φ:

一阶近似（小 dt，参考 KF-GINS）:
  Φ ≈ I + F * dt

高阶近似（大 dt 或高精度场景）:
  Φ = exp(F * dt)    （矩阵指数，可用泰勒展开或 Pade 逼近）

本项目采用一阶近似（IMU 采样率 100Hz，dt=0.01s，一阶足够精确）。
```

### 6.3 过程噪声 Q

参考 [imu.md 第 7.4 节](file:///home/mxl/workplace/gipylib/skills/imu.md#74-过程噪声矩阵-q)：

```
Q 仅有以下非零子块（离散化后）:
  Q[6:9, 6:9]   = (σ_gyro * sqrt(dt))² * I₃          姿态误差
  Q[3:6, 3:6]   = (σ_accel * sqrt(dt))² * I₃         速度误差
  Q[9:12, 9:12] = (σ_bg * sqrt(dt))² * I₃            陀螺零偏驱动
  Q[12:15,12:15]= (σ_ba * sqrt(dt))² * I₃            加计零偏驱动
  Q[15:17,15:17]= (σ_angle * sqrt(dt))² * I₂         安装角驱动（可选）
  Q[17:20,17:20]= (σ_l_imu * sqrt(dt))² * I₃         IMU杆臂驱动（可选）
  Q[20:23,20:23]= (σ_l_gnss * sqrt(dt))² * I₃        GNSS杆臂驱动（可选）

噪声参数来源: data/config.yaml 的 ins 段
  velocity_random_walk   → σ_accel
  attitude_random_walk   → σ_gyro
  gyro_bias_std          → σ_bg
  acce_bias_std          → σ_ba
  imu_angle_std          → σ_angle
  imu_leverarm_std       → σ_l_imu
```

### 6.4 TransferMatrix 类设计

```python
class TransferMatrix:
    """状态转移矩阵与过程噪声构造器

    参考 GINav update_trans_mat.m
    """

    def __init__(self, config):
        self.dim = self._compute_dim(config)  # 15/18/20/23
        self.noise_params = self._load_noise(config)

    def build_F(self, state, dt) -> np.ndarray:
        """构造连续时间 F 矩阵 (dim x dim)

        E 系下误差传播矩阵，参考 imu.md 第 7.2-7.3 节
        """
        F = np.zeros((self.dim, self.dim))
        # 位置误差方程 (0:3, :)
        F[0:3, 3:6] = np.eye(3)                          # F_rv = I_3
        # 速度误差方程 (3:6, :)
        F[3:6, 3:6] = -2 * skew(EARTH_RATE_ECEF)         # F_vv = -[2ω_ie^e ×]
        F[3:6, 6:9] = skew(state.f_e)                    # F_vφ = [f^e ×]
        F[3:6, 12:15] = -state.C_b_e                     # F_va = -C_b^e
        # 姿态误差方程 (6:9, :)
        F[6:9, 6:9] = -skew(EARTH_RATE_ECEF)             # F_φφ = -[ω_ie^e ×]
        F[6:9, 9:12] = -state.C_b_e                      # F_pb = -C_b^e
        # 零偏方程 (一阶马尔可夫)
        F[9:12, 9:12] = -np.eye(3) / tau_gyro            # F_bb
        F[12:15, 12:15] = -np.eye(3) / tau_accel          # F_aa
        # 安装角/杆臂假设为常数，F 中对应行为 0
        return F

    def build_Phi(self, F, dt) -> np.ndarray:
        """离散化状态转移矩阵 Φ ≈ I + F*dt"""
        return np.eye(self.dim) + F * dt

    def build_Q(self, dt) -> np.ndarray:
        """构造过程噪声矩阵 Q"""
        Q = np.zeros((self.dim, self.dim))
        # ... 按 6.3 节填充
        return Q
```

## 7. 与 GNSS 量测更新的衔接

> **本节是本文档的核心**：规划机械编排如何联动 GNSS 数据进行量测更新。

### 7.1 松组合量测模型

参考 KF-GINS `gi_engine.cpp::gnssUpdate` 与 [estimator.md](file:///home/mxl/workplace/gipylib/skills/estimator.md)：

```
松组合量测（GNSS 提供 ECEF 位置/速度）:
  z = [r_gnss^e, v_gnss^e]^T                    量测向量 (6x1)
  H = [I_3  0_3  0_3  0_3  0_3  0_2  0_3  0_3]  量测矩阵 (6 x N)
      [0_3  I_3  0_3  0_3  0_3  0_3  0_3  0_3]
  R = diag(σ_pos², σ_pos², σ_pos², σ_vel², σ_vel², σ_vel²)  量测噪声 (6x6)

量测残差:
  y = z - H * x_pred    （x_pred 为预测误差状态，通常为 0）

注: 若 GNSS 仅提供位置（无速度），则 z = [r_gnss^e]^T (3x1)，H 仅含位置行
    若 GNSS 提供协方差，则 R 来自 GnssSolution.cov；否则使用 default_pos_std/default_vel_std
```

### 7.2 量测更新触发条件

量测更新**不是每个 IMU 历元都执行**，而是在 GNSS 历元到达时触发。触发条件：

1. **AlignedBlock.gnss 不为 None**：当前批次包含 GNSS 解
2. **GNSS 解有效**：`GnssSolution.mode` 为 `SPP`/`RTD`/`RTK_FIXED`/`RTK_FLOAT`/`External` 之一
3. **时间对齐成功**：GNSS 时间戳 `t_gnss` 与 IMU 时间区间满足 4 种情况之一（第 7.4 节）

### 7.3 量测更新流程

```
function gnss_meas_update(state_pred, P_pred, gnss, config) -> (state_corrected, P_corrected):

  ┌────────────────────────────────────────────────────────────┐
  │ 1. 提取 GNSS 量测                                          │
  │    z_pos = gnss.pos_e           (ECEF 位置, 3x1)           │
  │    z_vel = gnss.vel_e (if any)  (ECEF 速度, 3x1)           │
  │    z = concat([z_pos, z_vel])   (6x1 或 3x1)               │
  │                                                            │
  │ 2. 构造量测矩阵 H                                          │
  │    H_pos = [I_3, 0_3, 0_3, ...]  (3 x N)                  │
  │    H_vel = [0_3, I_3, 0_3, ...]  (3 x N)                  │
  │    H = concat([H_pos, H_vel])    (6 x N 或 3 x N)          │
  │                                                            │
  │ 3. 构造量测噪声 R                                          │
  │    if gnss.cov is available:                               │
  │      R = gnss.cov (从 GnssSolution.cov 提取)               │
  │    else:                                                   │
  │      R = diag(σ_pos², σ_pos², σ_pos², σ_vel², ...)        │
  │      σ_pos = config.default_pos_std                       │
  │      σ_vel = config.default_vel_std                       │
  │                                                            │
  │ 4. 计算量测残差                                            │
  │    y = z - H * x_pred                                      │
  │    （x_pred 通常为 0，因为机械编排后误差状态归零）         │
  │    实际: y = z - [state_pred.pos_e, state_pred.vel_e]      │
  │                                                            │
  │ 5. 计算 Kalman 增益                                        │
  │    S = H * P_pred * H^T + R                                │
  │    K = P_pred * H^T * inv(S)                               │
  │                                                            │
  │ 6. 状态更新（误差状态）                                    │
  │    dx = K * y                                              │
  │                                                            │
  │ 7. 协方差更新（Joseph form，参考 estimator.md 第 3.2 节） │
  │    P_corrected = (I - K*H) * P_pred * (I - K*H)^T          │
  │                  + K * R * K^T                             │
  │    P_corrected = 0.5 * (P_corrected + P_corrected^T)       │
  │                                                            │
  │ 8. 状态反馈（第 8.4 节，ψ-error 模型）                     │
  │    state_corrected = feedback()                            │
  └────────────────────────────────────────────────────────────┘
```

### 7.4 时间对齐（4 种情况）

参考 KF-GINS `isToUpdate` 与 [imu.md 第 5.5-5.6 节](file:///home/mxl/workplace/gipylib/skills/imu.md#55-四种时间对齐情况)、[初始化.md 第 4.4 节](file:///home/mxl/workplace/gipylib/skills/初始化.md#44-4-种时间对齐情况参考-kf-gins-isoupdate)：

```
function is_to_update(t0, t2, t_gnss, threshold=1e-3) -> int:
  # t0: imupre.timestamp, t2: imucur.timestamp, t_gnss: GNSS 时间戳
  if abs(t0 - t_gnss) < threshold:
    return 1  # GNSS 靠近 t0
  elif abs(t2 - t_gnss) <= threshold:
    return 2  # GNSS 靠近 t2
  elif t0 < t_gnss < t2:
    return 3  # GNSS 在中间，需增量切分
  else:
    return 0  # GNSS 时间不在 [t0, t2] 之间
```

**4 种情况的处理**（机械编排视角）：

| 情况 | 条件 | 机械编排处理 | 量测更新时机 |
|------|------|-------------|-------------|
| 0 | `t_gnss` 不在 `[t0, t2]` 之间 | 仅执行 INS 传播 `t0→t2` | **不触发**量测更新（除非 GNSS 历元属于另一个 AlignedBlock） |
| 1 | `\|t0 - t_gnss\| < 1ms` | 先在 `t0` 时刻执行 GNSS 量测更新，再传播 `t0→t2` | **更新→传播** |
| 2 | `\|t2 - t_gnss\| < 1ms` | 先传播 `t0→t2`，再在 `t2` 时刻执行 GNSS 量测更新 | **传播→更新** |
| 3 | `t0 < t_gnss < t2` | 增量切分：传播 `t0→t_gnss` → GNSS 量测更新 → 传播 `t_gnss→t2` | **传播→更新→传播** |

### 7.5 量测更新的执行方

**重要约定**：量测更新（Kalman 增益、状态更新、协方差更新）的执行方是 `LcIntegration`（估计器），**不是** `ImuMechanizer`（机械编排器）。`ImuMechanizer` 的职责是：
1. 完成机械编排预测（状态 + Φ + Q）
2. 判断是否触发量测更新（4 种情况）
3. 提供量测更新所需的数据（H, z, R）

`LcIntegration` 的职责是：
1. 接收 `ImuMechanizer` 的预测输出
2. 执行 EKF 时间更新（GINav 中间值法：`P = Φ·(P + 0.5Q)·Φ^T + 0.5Q`）
3. 若触发量测更新，执行 EKF 量测更新（Joseph form，第 7.3 节）
4. 执行单滤波统一反馈（第 8.4 节）

```
ImuMechanizer                              LcIntegration
─────────────                              ──────────────
process_epoch:
  1. imu_compensate                        time_update:
  2. InsCore.update (预测)        ──→        P = Φ·(P+0.5Q)·Φ^T + 0.5Q
  3. build Φ, Q                   ──→
  4. is_to_update(t0,t2,t_gnss)
  5. if 触发:                       meas_update (if triggered):
     build H, z, R                 ──→      S = H·P·H^T + R
                                          K = P·H^T·S^{-1}
                                          dx = K·(z - H·x)
                                          P = (I-KH)·P·(I-KH)^T + K·R·K^T
                                        ↓
                                  feedback():
                                    ψ-error 反馈 ←─ ImuMechanizer.feedback
                                    P 保留更新后值
```

### 7.6 量测更新的坐标系处理

```
GNSS 解算结果坐标系: ECEF (x, y, z)
INS 状态坐标系:     ECEF (pos_e, vel_e)
量测更新坐标系:     ECEF（一致，无需转换）

特殊情况:
  - 外部 GNSS 结果文件 (.pos) 通常为 lat/lon/h + ENU 速度
    → 需在 GnssSolSensor 加载时转换为 ECEF
    → 参考 src/stream/gnss_sol_sensor.py 的实现
  - 协方差矩阵: 若外部结果提供 ENU 协方差，需旋转到 ECEF
    → 参考 SolutionWriter 的 ENU 协方差处理
```

## 8. 单滤波架构下的机械编排

> 单滤波架构详见 [estimator.md 第 1-3 节](file:///home/mxl/workplace/gipylib/skills/estimator.md)。本节描述机械编排如何驱动单一 P 矩阵的 EKF。
>
> **核心特征**：所有误差状态（位置/速度/姿态/零偏 + 可选 GNSS 杆臂/IMU 安装角/IMU 杆臂/时间对齐）合并到同一个 P 矩阵中，NHC/ZUPT 量测与 GNSS 量测都直接作用于该 P，无主/子滤波分离。

### 8.1 单一 P 矩阵与状态向量（StateIndex 参数块）

```
单一 P 矩阵（E 系，参考 estimator.md 第 2 节 StateIndex）:
  x = [δr^e, δv^e, δψ^e, δb_g, δb_a, (δl_gnss), (δθ_imu), (δl_imu), (δt)]^T
       0-2   3-5   6-8   9-11  12-14  15-17    18-19    20-22    23

固定 15 维（始终估计，E 系 ψ-error 模型）:
  δr^e    : ECEF 位置误差 (m)               [0:3]
  δv^e    : ECEF 速度误差 (m/s)             [3:6]
  δψ^e    : ECEF 姿态误差角 (rad)            [6:9]   C_b^e_true = (I - [δψ^e×])·C_b^e_est
  δb_g    : 陀螺零偏误差 (rad/s)            [9:12]
  δb_a    : 加计零偏误差 (m/s²)             [12:15]

可选参数块（未启用时索引为 -1，不占 P 维度）:
  δl_gnss : GNSS 天线杆臂误差 (m, b 系)     [15:18]  estimate_leverarm=1
  δθ_imu  : IMU 安装角误差 [δpitch, δyaw]  [18:20]  estimate_mounting_angle=1
  δl_imu  : IMU 杆臂误差 (m, b 系)          [20:23]  estimate_imu_leverarm=1（需 mounting_angle 启用）
  δt      : 时间对齐误差 (s)                [23]     estimate_time_sync=1

P 维度 = StateIndex.dim（默认 15，全启用 24），由配置在初始化时一次性确定，运行期不变。
```

### 8.2 时间更新（GINav 中间值法）

```
单一 P 时间更新（每个 IMU 历元，参考 estimator.md 第 3.1 节）:
  x_pred = 0                    （机械编排后误差状态归零）
  P = Φ·(P + 0.5Q)·Φ^T + 0.5Q  （GINav 中间值法，二阶精度）
  P = 0.5·(P + P^T)             （强制对称）

构造步骤:
  1. IMU 误差补偿: dtheta_comp = dtheta - gyro_bias·dt, dvel_comp = dvel - accel_bias·dt
  2. INS 机械编排（E 系，参考第 5 节 / imu.md 第 6 节）
  3. 构造 F 矩阵（ψ-error, E 系，参考 ignav getF，含可选块零行零列）
  4. 离散化 Φ（自适应精度: dt≤0.005s 一阶, dt≤0.01s 二阶, dt>0.01s 矩阵指数）
  5. 构造 Q 矩阵（GINav G·Q_diag·G^T 风格，仅非零子块）
  6. P 传播 + 对称化

异常间隔：若 `InsUpdate.last_update_accepted` 为假（`dt <= 0`、
`dt < 1e-6 s` 或 `dt > 60 s`），不得构造 `F/Phi/Q` 或传播 `P`。
其中正 `dt` 的异常样本应更新时间边界并清空上一历元的锥补/划桨增量，
防止下一有效样本跨越该间隔积分。
```

### 8.3 量测更新（Joseph form，序贯作用于同一 P）

```
单一 P 量测更新（参考 estimator.md 第 3.2 节 / 第 4 节）:

序贯更新顺序: GNSS 位置 → GNSS 速度 → NHC/ZUPT（每个独立执行 Joseph form）

每个量测子更新的统一公式:
  S = H·P·H^T + R
  K = P·H^T·S^{-1}
  x = x + K·(Z - H·x)
  P = (I - K·H)·P·(I - K·H)^T + K·R·K^T     （Joseph form，保证对称正定）
  P = 0.5·(P + P^T)

量测类型（均作用于同一 P，H/R 维度不同）:
  ├── GNSS 位置: Z = pos_e - gnss.position,  H[:, pos]=I_3 + (lever_arm/time_sync 项)
  ├── GNSS 速度: Z = vel_e - gnss.velocity,  H[:, vel]=I_3 + (att/lever_arm/time_sync 项)
  ├── NHC（运动时）: Z = v^v[1:3] (侧向+垂向, 期望 0), H 含 vel/att/gyro_bias/imu_angle/imu_leverarm
  └── ZUPT（静止时, speed < static_speed_threshold）: Z = vel_e (3D 归零), H[:, vel]=I_3

NHC 与 ZUPT 互斥: 静止用 ZUPT，运动用 NHC。NHC 量测使用单一 H 矩阵（无主/子量测矩阵分离）。
```

### 8.4 单滤波统一反馈（ψ-error 模型）

参考 KF-GINS `stateFeedback` 与 [estimator.md 第 5 节](file:///home/mxl/workplace/gipylib/skills/estimator.md#5-反馈机制)：

```
function feedback():    # 无参，内部从 dx 反馈

  ┌─────────────────────────────────────────────────────┐
  │ ψ-error 反馈（E 系，pos/vel/att 减法，bias 加法）   │
  │                                                     │
  │ state.pos_e       -= dx[0:3]      # 位置: 减法      │
  │ state.vel_e       -= dx[3:6]      # 速度: 减法      │
  │ state.C_b_e       = (I - [dx[6:9]×]) @ C_b_e        │
  │                                   # 姿态: 减法 (ψ-error)
  │ state.q_b_e       = dcm2quat(state.C_b_e)           │
  │ state.C_b_e       = svd_orthogonalize(state.C_b_e)  # SVD 正交化
  │ state.gyro_bias   += dx[9:12]     # 陀螺零偏: 加法  │
  │ state.accel_bias  += dx[12:15]    # 加计零偏: 加法  │
  └─────────────────────────────────────────────────────┘
                              ↓
  ┌─────────────────────────────────────────────────────┐
  │ 可选参数块反馈（仅当对应 StateIndex 索引 ≥ 0）      │
  │                                                     │
  │ if si.lever_arm ≥ 0:                                │
  │   state.leverarm    += dx[si.lever_arm : si.lever_arm+3]   # GNSS 杆臂: 加法
  │ if si.imu_angle ≥ 0:                                │
  │   state.imu_angle   += dx[si.imu_angle : si.imu_angle+2]  # IMU 安装角: 加法
  │   Nhc.update_from_state()    # 刷新 R_b^v
  │ if si.imu_leverarm ≥ 0:                             │
  │   state.imu_leverarm -= dx[si.imu_leverarm : si.imu_leverarm+3]  # IMU 杆臂: 减法
  │ if si.time_sync ≥ 0:                                │
  │   state.time_sync   += dx[si.time_sync]    # 时间对齐: 加法
  └─────────────────────────────────────────────────────┘
                              ↓
  ┌─────────────────────────────────────────────────────┐
  │ 误差状态归零                                        │
  │                                                     │
  │ dx = 0                                              │
  │ （下一次机械编排从全状态出发，误差状态归零）        │
  │ Nhc.update_from_state() 已在上一步刷新 R_b^v        │
  └─────────────────────────────────────────────────────┘
```

**单滤波统一反馈的关键**：
- 仅一个 P 矩阵，反馈后误差状态 `dx` 整体归零（无主/子滤波分离）
- ψ-error 模型：pos/vel/att 用**减法**反馈（`state -= dx`），bias/杆臂/安装角/时间用**加法**反馈（`state += dx`）
- 姿态反馈后 SVD 正交化防数值漂移
- NHC 相关状态（IMU 安装角/IMU 杆臂）反馈后调用 `Nhc.update_from_state()` 刷新 `R_b^v`
- 反馈后下次机械编排从全状态出发，误差状态归零

### 11.3 与 NHC 量测更新的衔接

NHC 量测更新由 `LcIntegration` 在每个 IMU 历元（或按策略）触发，与 GNSS 量测更新序贯作用于**同一个 P 矩阵**（不再有独立的 NHC 子滤波）：

```

  ├── 单一 P 时间更新: P = Φ·(P+0.5Q)·Φ^T + 0.5Q  (GINav 中间值法)
  ├── NHC 量测更新 (运动时, 作用于同一 P):
  │     S=H·P·H^T+R; K=P·H^T·S^{-1}; dx=K·(Z-H·x)
  │     P=(I-KH)·P·(I-KH)^T+K·R·K^T
  │   或 ZUPT 量测更新 (静止时, speed < static_speed_threshold)
  └── (无 GNSS 量测更新, 除非 res != 0)

  ├── 单一 P 时间更新
  ├── GNSS 位置量测更新 (Joseph form, 作用于同一 P)
  ├── GNSS 速度量测更新 (Joseph form, 作用于同一 P)
  ├── NHC/ZUPT 量测更新 (按运动状态选择)
  └── 单滤波统一反馈 feedback()  (ψ-error, 第 8.4 节)
```

## 12. 异常处理与降级

### 12.1 协方差检查

参考 KF-GINS `gi_engine.cpp::checkCov`：

```
function check_cov(P):
  # 1. 对称性检查
  if not is_symmetric(P):
    P = (P + P^T) / 2    # 强制对称

  # 2. 正定性检查
  eigvals_P = eigvals(P)
  if any(eigvals_P <= 0):
    P = nearest_pd(P)    # 最近正定矩阵

  # 3. 协方差发散检查（第 13.6 节 reboot 触发）
  if max(diag(P)) > config.cov_divergence_threshold:
    trigger_reboot(COV_DIVERGENCE)
```

## 15. 机械编排漂移问题的实测结论（2026-08-17）

本节记录 `issue/8-11机械编排bug.md` 的最终验证结果，优先级高于早期“机械编排公式错误”假设。

### 15.1 先区分“量测间漂移”和“量测后常值速度偏差”

在 GPS-only、100 Hz、GPS week 2046、SOW 359000--359100 窗口中，逐历元比较 Qins=3（量测反馈后）与紧邻 Qins=2（下一次量测前）的速度：

- 量测间机械编排速度变化中位约 `0.011 m/s`，最大约 `0.068 m/s`，机械编排本身没有原先认为的巨大离散跳变。
- 真正异常是 Qins=3 相对真值约 `1 m/s` 的常值速度偏差；量测更新只能修正其中一部分。
- 纯机械编排回放仍须单独检查 IMU 比力、初始姿态、重力、科氏项和时间窗口，不能把所有速度偏差都归因于协方差。

### 15.2 TC 的过程噪声边界

ignav TC 的 `insudsta()` 不添加位置/速度随机游走，TC 协方差主要由 IMU 传播中的 `getQ()` 与状态转移矩阵传播得到。因此：

- TC 配置中 `pos_psd` 应为 `0.0`；`pos_psd=5.0` 会通过位置-速度交叉协方差人为污染速度估计。
- `vel_psd=0.5` 在当前系统中仍需保留；实验表明同时将 `pos_psd` 和 `vel_psd` 清零会导致协方差过度收缩、滤波退化。
- 该规则只适用于 TC。LC 的位置量测可能使 `P_pos` 坍缩，LC 必须根据自身量测模型保留非零 `pos_psd`。

决定性 GPS-only 对照结果：`pos_psd: 5.0 -> 0.0` 后，Q3 速度误差中位数约 `0.997 -> 0.100 m/s`，Q2 速度误差中位数/峰值约 `1.186/1.627 -> 0.263/0.553 m/s`；多星座正式 TC 配置达到约 `0.0985 m/s` Q3 速度误差、`0.463 m` Q3 位置误差。

### 15.3 模糊度管理与后验保护

RTK TC 必须复用或等价实现 rtklib 的 `udbias()` 生命周期：LLI/Doppler/geometry-free 周跳检测、失锁计数、`prnbias^2 * abs(tt)` 过程噪声、phase-code 重初始化和状态槽位同步。TC 与 rtklib ambiguity 布局不同，映射时不能直接复制整个状态数组。

后验 RTK 量测需在 EKF 更新后、feedback 前执行 ignav `valpos()` 等价检查。拒绝时恢复更新前的 `x/P`，保留上一 INS 状态；已有量测但后验拒绝不得立即用粗粒度 SPP 恢复覆盖 INS。

### 15.4 验收与排查顺序

出现量测间速度异常时，按以下顺序检查：

1. 先按 Qins 分离量测后状态、量测间状态和反馈增量，确认是常值偏差还是传播增长。
2. 核对 TC/LC 模式的 `pos_psd` 边界，不得把 TC 的修复直接推广到 LC。
3. 核对相位接受率、ambiguity 生命周期和后验拒绝数量。
4. 再逐项核对 RFU→FRD、IMU 时间、姿态方向、重力、科氏项和比力投影。
5. 与 ignav 对比时，优先使用其 `.stat` 中正确换算的 INS `$POSI/$VELACCI`；ignav 100 Hz 重跑结果的速度列存在系统性差异，不能直接作为量测间漂移金标准。

### 15.5 与 ignav `updateins()` 的数值对齐补充

- `rotscull_corr()` 的极小角分支必须用 `a1=1/2-theta^2/24+theta^4/720` 和 `a2=1/6-theta^2/120+theta^4/5040`，不能把旋转补偿直接置零。
- 名义速度积分使用普通 `gravity()` 等价的 `gravity_ecef_normal()`；误差状态重力梯度仍使用 `pregrav()` 等价的 `gravity_ecef()`。二者在 CPT 位置约差 `4e-5 m/s^2`，虽不解释历史的米每秒级偏差，但必须保持参考实现的职责分离。
- `updateins()` 的无效 IMU 间隔也必须阻止协方差传播。`InsUpdate.last_update_accepted` 是 `LcEstimator` 和 `TcEstimator` 的共享门限，避免 P 在被拒绝的名义状态间隔上跨越式外推。
