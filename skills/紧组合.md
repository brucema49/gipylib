# GNSS/INS 紧组合设计方案

> **当前状态索引（2026-09-15）**：`src/core/tc/` 的 SPP/RTK/RTD 紧组合主链已实现；TC 模糊度已完成 SD→DD、正定保护、异常降级和健康门控修复。正式 RTK-TC MECH-16 基线与独立 AR 分支必须分开报告；BDS、门限、INS 三段 schema（`pos_psd`/`vel_psd` 的 LC-only 归属）以 [项目当前状态](项目当前状态.md) 第 4.4 节为准。

> 实现 SPP-INS / RTK-INS / RTD-INS 三种紧组合模式，源代码统一放置于 `src/core/tc/` 目录。
>
> **核心设计原则**（与 ignav 的本质区别）：
> - **不在 `src/core/gnss/` 中强行融入 INS 代码**：GNSS 模块保持纯 GNSS 解算能力，不感知 INS 的存在
> - **在 `src/core/tc/` 中完成融合**：紧组合模块调用 INS 机械编排（`src/core/ins/`）+ GNSS 原始观测处理（`src/core/gnss/rtklib/` 的工具函数），在 tc 层构造紧组合量测方程并完成 EKF 融合
> - **参考 GREAT-MSF 的解耦思想**：INS 与 GNSS 各自维护独立逻辑，通过 tc 层的量测方程构造（H 矩阵 + 残差）实现耦合，而非像 ignav 那样让 INS 直接调用 `rtkpos` 共享 `rtk_t` 结构
> - **SPP-INS 量测方程参考 ignav/GINav**：伪距残差 `v = P − (r + dtr − c·dts + dion + dtrp)`，H 矩阵含位置偏导 `LOS` 与钟差偏导
> - **RTK-INS 架构参考 GREAT-MSF**：双差残差 + INS 参数耦合进观测矩阵，但用组合而非多重继承
>
> **与松组合的关键差异**：
> - 松组合（`src/core/ins/lc_*.py`）：GNSS 解算出 `GnssSolution`（位置/速度）后作为量测喂入 EKF，量测是 3 维位置
> - 紧组合（`src/core/tc/`）：GNSS 只提供原始观测（伪距/载波/多普勒）+ 星历，tc 模块用 INS 推算的位置预测观测值并构造残差，量测是 N 维原始观测（N=可见卫星数×频率）
> - 紧组合优势：GNSS 信号部分遮挡时仍可用（少于 4 颗卫星也能量测更新）、无需 GNSS 独立解算收敛、INS 先验提升 GNSS 模糊度固定成功率
>
> **坐标系与符号约定**（与 [imu.md](file:///home/mxl/workplace/gipylib/skills/imu.md) 一致）：
> - 机械编排在 **E 系（ECEF）** 下进行
> - 体坐标系 b 系：**FRD**（前-右-下）
> - 误差状态约定：`δx = x_est − x_true`（估计值减真值），反馈时 `state -= δx`
> - 视线向量 `LOS = (sat − rcv) / |sat − rcv|`（接收机指向卫星的单位向量）
> - 几何距离 `r = |sat − rcv|`，`∂r/∂rcv = −LOS`
>
> **当前实现与验证状态（2026-8-26）**：
> - ✅ 已实现：`src/core/tc/` 的 RTD/RTK 紧组合主链路（TcEstimator / TcMeasurement / TcIntegration / TcStream / TcDegradeManager）。
> - ✅ 已验证：统一评估和状态级评估已覆盖整数秒更新点、100 Hz 传播点、E/N/U、姿态、零偏和更新诊断；`data/plot/error-state.py` 已实现，不再是占位文件。
> - ✅ Data19 BDS：SPP/TC 使用四维接收机钟差 `[GPS,GLO,GAL,BDS]`，BDS 通过 B1I/B2I、BDT->GPST 和 GEO 轨道修正进入量测；GPS+BDS RTK 固定率 `99.7%`，与 RTKLIB 双 FIX 解差 RMSE `2.7 cm`。
> - ✅ 当前 RTK 门限基线：`prnbias: 0.03`、`maxinno: 5.0`（相位）、`maxcode: 30.0`（伪距）。`maxinno=30` 不是等价替代，会掩盖未初始化模糊度行。
> - ✅ 最新验收（`8-23/MECH-13`）：目标窗口水平 RMSE `0.0488 m`，ignav 参照 `0.0516 m`；全段 `0.2601 m`，与本轮基线持平；传播速度差约 `0.093 m/s`。纯 GNSS 结果未受本轮 TC 配置变化影响。
> - ✅ 机械编排 harness 对照：相同初始状态和 IMU 下，gipylib `InsUpdate` 与 ignav `updateins()` 100 s 累计速度差约 `6.6e-6 m/s`，名义机械编排公式不是当前主要根因。
> - ✅ 已完成 TC AR 缺陷修复验证：`mlambda.LD()` 非正定已改为可降级处理，TC 模糊度 SD→DD、PD 防护、过程噪声和健康门控已完成验证；`armode=3` 分支窗口可达约 `0.019 m`。当前正式 MECH-13 仍使用 `armode=0`，AR 只作为独立分支，不能把 AR 收益与机械编排收益混为一谈。
> - ✅ 可复用：`src/core/ins/` 全部机械编排、状态传播与反馈模块，以及 `src/core/gnss/rtklib/` 的 GNSS 工具函数。

当前剩余风险：误差状态中的 pitch 约 `0.6°`、yaw 约 `1.6°` 仍未完全收敛；加计零偏虽已恢复可观测，但机动段和量测间速度漂移尚未达到 ignav 的约 `2--4 cm/s` 水平。后续修改必须继续保持纯 GNSS → TC 的前后评估顺序，不得把 `vel_psd` 单独调小而跳过创新门限、杆臂和零偏先验的联合验证。

### 精度验证与变更纪律

紧组合修改必须遵循“基线评估 → 单变量修改 → 同口径复评 → 接受或回退”：

1. 修改前冻结配置、输入、命令、评估脚本和输出，并先完成纯 GNSS（RTK/RTD）评估，再完成 RTK/RTD-TC 评估。
2. 修改后使用同一真值、时间窗、整数秒最近点规则、坐标基准和误差脚本，比较 E/N/U、水平 RMSE、最大误差、有效历元和 GNSS 更新率。
3. 关键指标任一恶化、出现跳变或有效更新减少，立即回退到上一通过配置，不在失败候选上叠加修改。
4. RTKLIB C 仅作交叉参考；若按 RTKLIB 观测/频率策略对齐后结果仍恶化，必须保留对照证据并向用户请示，标记为后续处理，不能自行切换参数掩盖恶化。

## 1. 概述与设计原则

### 1.1 设计目标

实现三种紧组合模式，统一放置于 `src/core/tc/`：

| 模式 | GNSS 量测类型 | 参考项目 | 适用场景 |
|------|-------------|---------|---------|
| **SPP-INS TC** | 伪距 + 多普勒（零差） | ignav `tcigpos` / GINav `sppins` | 单机定位，无基站 |
| **RTK-INS TC** | 双差载波 + 双差伪距 | GREAT-MSF `t_gintegration` / GINav `rtkins` | 有基站，高精度 |
| **RTD-INS TC** | 双差伪距（无载波） | GINav `rtkins`（仅伪距分支） | 有基站，无需模糊度固定 |

### 1.2 核心设计原则

```
┌─────────────────────────────────────────────────────────────────┐
│  src/core/gnss/  (纯 GNSS，不感知 INS)                           │
│    rtklib/geodist, satazel, satposs, prange, ionmodel, tropmodel│
│    rtklib/ddres, resamb_LAMBDA (可被 tc 复用，但不修改)          │
│    spp_processor, rtk_processor (松组合用，紧组合不复用)         │
└──────────────────────────┬──────────────────────────────────────┘
                           │ 原始观测 + 星历 (obsd_t, nav_t)
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│  src/core/tc/  (紧组合融合层 — 主滤波)                           │
│    TcMeasurement: 构造 H 矩阵 + 残差 v + 噪声 R                 │
│      ├── SppTcMeas:  H_pos=LOS, H_clk=1, v=P-(r+dtr-c·dts+...) │
│      ├── RtkTcMeas:  H_pos=ΔLOS, H_att=ΔLOS·askew(lever), H_amb│
│      └── RtdTcMeas:  H_pos=ΔLOS (仅双差伪距)                   │
│    TcEstimator: 扩展 LcEstimator，管理 INS+GNSS 联合状态        │
│      ├── 残差输出接口 (先验/后验残差 + H/R/P 快照)              │

│      ├── 降级策略 (RTK→RTD→SPP→IMU 机械编排)                   │

│      └── 约束外部化到 src/core/motion (NHC/ZUPT/ZARU)           │
│    TcDegradeManager: 降级状态机 + reboot 计时                   │
│    TcResiduals: 残差输出接口 (prior/posterior)                  │
│    TcStream: 流式运行器 (per-IMU 输出 .rslt)                    │
└─────────┬───────────────────────────────┬───────────────────────┘
          │ 调用机械编排 + P 传播          │ 约束请求 (per-IMU)
          ▼                                ▼
┌──────────────────────────┐  ┌──────────────────────────────────┐
│  src/core/ins/           │  │  src/core/motion/  (约束层)       │
│  (纯 INS，不感知 GNSS)   │  │    MotionConstraintManager        │
```

**关键解耦点**：
1. `src/core/gnss/` 中的函数只接收 ECEF 位置/星历/观测，返回 LOS/残差/卫星位置，**不接收 InsState**
2. `src/core/tc/` 中的模块**调用** ins 的 `LcEstimator`（机械编排 + P 传播 + joseph_update）和 gnss 的工具函数（geodist/satposs 等），在 tc 层组装紧组合量测方程
3. `src/core/ins/` 中的 `LcEstimator` **不修改**，紧组合通过继承 `TcEstimator(LcEstimator)` 扩展状态向量与量测接口
4. **主滤波 + 约束分离**：紧组合（`src/core/tc/`）与松组合（`src/core/ins/lc_*.py`）同为主滤波器，NHC/ZUPT/ZARU 等运动约束统一外置到 `src/core/motion/`，通过伪量测接口注入主滤波（详见 [第18章](#18-主滤波与约束分离src-coremotion)）
5. **降级链路**：紧组合支持 RTK→RTD→SPP→IMU 机械编排的多级降级，达 reboot 阈值后重启但保留随机游走类参数（详见 [第16章](#16-降级策略与重启机制)）
6. **残差透明**：主滤波每次量测更新的先验残差（v/H/R/P）与后验残差都通过 `TcResiduals` 接口输出，供 `src/core/robust/` 抗差估计模块消费（当前预留，暂不执行，详见 [第17章](#17-残差输出接口与抗差估计预留)）

### 1.3 与 ignav 的本质区别

| 维度 | ignav `tcigpos` | 本项目 `src/core/tc/` |
|------|----------------|----------------------|
| **GNSS 解算** | INS 直接调用 `rtkpos()`，共享 `rtk_t` 结构 | tc 层构造伪距/双差残差，调用 `LcEstimator.joseph_update` |
| **状态管理** | `insstate_t` 与 `rtk_t` 共享 `x`/`P` 矩阵 | `TcEstimator` 统一管理，GNSS 参数（钟差/模糊度）作为可选块 |
| **耦合方式** | 强耦合：INS 代码写入 `rtk->sol.rr` 供 rtkpos 使用 | 解耦：tc 层从 InsState 读取位置，构造 H 矩阵后调用 joseph_update |
| **GNSS 模块修改** | 需修改 rtkpos 以读取 INS 状态 | **不修改** `src/core/gnss/`，只复用工具函数 |

### 1.4 与 GREAT-MSF 的异同

| 维度 | GREAT-MSF `t_gintegration` | 本项目 `src/core/tc/` |
|------|---------------------------|----------------------|
| **架构** | 多重继承 `t_gsinskf` + `t_gpvtflt` | 组合：`TcEstimator` 持有 `LcEstimator` + GNSS 参数块 |
| **融合方式** | `_merge_pose(A)` 修改 GNSS 观测矩阵 A，统一 `_filter->update` | tc 层构造完整 H/v/R，调用 `joseph_update` |
| **坐标系** | n 系（BLH 位置，需 T 雅可比） | E 系（ECEF，无需 T） |
| **反馈** | `_feedback` 分离 INS/GNSS 参数分别反馈 | 统一 `feedback()`，INS 参数复用 LcEstimator，GNSS 参数独立处理 |

## 4. 状态向量扩展（TcStateIndex）

### 4.1 状态向量布局

紧组合状态向量 = INS 基础 15 维 + 可选 INS 块 + GNSS 参数块：

```
δx = [δr^e, δv^e, δψ^e, δb_g, δb_a, δθ_imu, δl_imu, δl_gnss, δt_r, δN_amb]^T
       0-2   3-5   6-8   9-11  12-14  15-16   17-19   20-22   23    24...

INS 部分 (复用 StateIndex):
  pos(3), vel(3), att(3), gyro_bias(3), accel_bias(3)          — 固定 15 维
  imu_angle(2), imu_leverarm(3), lever_arm(3), time_sync(1)   — 可选 (继承 StateIndex)

GNSS 部分 (TcStateIndex 扩展):
  clk_bias(4): 接收机钟差 [dtr_gps, dtr_glo, dtr_gal, dtr_bds]  — SPP-INS 用 (零差需钟差)
  ambiguity(N): 双差模糊度，N = nsat × nf                       — RTK-INS 用 (RTD-INS 无此项)
```

### 4.2 TcStateIndex 类设计

```python
# src/core/tc/tc_state_index.py
from dataclasses import dataclass
from src.core.ins.state_index import StateIndex


@dataclass
class TcStateIndex(StateIndex):
    """紧组合状态参数块索引（继承 StateIndex，扩展 GNSS 参数块）。

    参考:
      - GREAT-MSF gallpar (统一参数管理)
      - GINav rtk.ic / rtk.ib / rtk.ii (钟差/模糊度/电离层索引)
      - 本项目 StateIndex (INS 参数块)

    状态顺序:
      INS 固定 15 维 + INS 可选块 (继承 StateIndex)
      + clk_bias(4)    SPP-INS 钟差 [dtr_gps, dtr_glo, dtr_gal, dtr_bds]
      + ambiguity(N)   RTK-INS 双差模糊度 (N = nsat × nf)
    """

    # GNSS 参数块 (-1 表示未启用)
    clk_bias: int = -1      # 4 维, 接收机钟差 (SPP-INS 用)
    ambiguity: int = -1     # N 维, 双差模糊度 (RTK-INS 用)
    n_amb: int = 0          # 模糊度个数

    @classmethod
    def from_config(cls, config: dict, mode: str = "spp") -> "TcStateIndex":
        """根据配置与紧组合模式构建状态索引。

        Args:
            config: 配置字典
            mode: 紧组合模式 ("spp" / "rtk" / "rtd")
        """
        # 先构建 INS 部分 (复用 StateIndex.from_config)
        si = super().from_config(config)
        # 转为 TcStateIndex
        tc_si = cls()
        tc_si.pos = si.pos
        tc_si.vel = si.vel
        tc_si.att = si.att
        tc_si.gyro_bias = si.gyro_bias
        tc_si.accel_bias = si.accel_bias
        tc_si.lever_arm = si.lever_arm
        tc_si.imu_angle = si.imu_angle
        tc_si.imu_leverarm = si.imu_leverarm
        tc_si.time_sync = si.time_sync
        tc_si.dim = si.dim

        idx = tc_si.dim

        # SPP-INS: 钟差参数 [dtr, dtr_glo, dtr_gal] (参考 GINav rtk.ic)
        if mode == "spp":
            tc_si.clk_bias = idx
            idx += 3

        # RTK-INS: 模糊度参数 (运行时动态扩展，初始为 0)
        # 模糊度个数取决于可见卫星数 × 频率数，在 TcAmbiguity 中动态管理
        if mode == "rtk":
            tc_si.ambiguity = idx  # 起始索引，个数由 n_amb 动态设置
            # idx += n_amb (运行时确定)

        # RTD-INS: 无钟差 (双差消除)、无模糊度 (仅伪距)

        tc_si.dim = idx
        return tc_si

    def has_clk_bias(self) -> bool:
        return self.clk_bias >= 0

    def has_ambiguity(self) -> bool:
        return self.ambiguity >= 0

    def amb_idx(self, sat: int, freq: int, na: int) -> int:
        """获取卫星 sat 频率 freq 的模糊度索引。

        参考 rtklib IB(sat, freq, na) 宏。
        """
        return self.ambiguity + freq * na + (sat - 1)
```

|------|-----------|--------------------------|------|
| 姿态 δψ | x(1:3) | si.att = 6 | GINav 姿态在前，本项目位置在前 |

## 5. 紧组合量测方程

### 5.1 SPP-INS TC（伪距 + 多普勒）

参考 ignav `tcigpos` + GINav `sppins` / `rescode_sppins`。

#### 5.1.1 伪距量测方程

```
伪距观测方程 (零差):
  P = r(rcv) + dtr − c·dts + dion + dtrp + ε

其中:
  P = prange(obs, nav)              伪距观测 (已减 TGD)
  r(rcv) = |sat − rcv|              几何距离 (INS 推算位置 rcv = state.pos_e)
  dtr = c·δt_r                      接收机钟差 (状态参数)
  dts = 卫星钟差                     (星历提供)
  dion = ionmodel(...)              电离层延迟 (广播模型)
  dtrp = tropmapf·tropmodel(...)    对流层延迟 (Saastamoinen)

残差 (量测减预测):
  v = P − (r + dtr − c·dts + dion + dtrp)

H 矩阵 (对应 δx = est − true 约定):
  H[si.pos : si.pos+3] = LOS        位置偏导 (∂r/∂rcv = −LOS, 但 δx=est−true 故 H=LOS)
  H[tc_si.clk_bias]    = 1          钟差偏导 (∂(dtr)/∂(δt_r) = 1)
  H[tc_si.clk_bias+1]  = 1          (GLO 系统, 可选)
  H[tc_si.clk_bias+2]  = 1          (GAL 系统, 可选)
  H[tc_si.clk_bias+3]  = 1          (BDS 系统, 可选)

  其中 LOS = (sat − rcv) / |sat − rcv|  (复用 rtkcmn.geodist 获取)

R 矩阵:
  R = diag(var_1, var_2, ..., var_n)
  var_i = varerr(nav, sys, el, ...)   (复用 pntpos.varerr 或 rtkpos.varerr)
```

#### 5.1.2 多普勒量测方程（可选）

```
多普勒观测方程 (零差):
  D = −LOS·(v_sat − v_rcv) + c·δḋ_r + ε_D

其中:
  D = obs.D[i, 0]                   多普勒观测 (Hz → m/s: D·λ)
  v_rcv = state.vel_e                INS 推算速度
  v_sat = 卫星速度                    (satposs 返回)
  δḋ_r = 钟差变率                     (可选状态, 简化时可忽略)

残差:
  v_D = D·λ − (−LOS·(v_sat − v_rcv) + c·δḋ_r)

H 矩阵:
  H[si.vel : si.vel+3] = −LOS       速度偏导 (δx=est−true, H=−LOS·(−1)=LOS? 需验证符号)
  H[tc_si.clk_bias]    = c           钟差变率偏导 (若估计)
```

> **符号验证**：`v_D = D·λ − h(v_est)`，`h = −LOS·(v_sat − v) + c·δḋ`，`∂h/∂v = LOS`。`δv = v_est − v_true`，`v_est = v_true + δv`，`h(v_est) ≈ h(v_true) + LOS·δv`，`v_D = D·λ − h(v_true) − LOS·δv = v_D0 − LOS·δv`。`innov = v_D − H·δx = v_D0 − LOS·δv − H·δv`，需 `H = −LOS` 使 `innov = v_D0`。所以 **`H_vel = −LOS`**。

#### 5.1.3 SPP-INS TC 量测更新流程

```
1. satposs(obs, nav, ephopt) → rs, dts, svh        [复用 rtklib]
2. rr = state.pos_e                                  [INS 推算位置]
3. pos = ecef2pos(rr)                                [复用 rtklib]
4. for each sat:
     r, LOS = geodist(rs[i], rr)                     [复用 rtklib]
     az, el = satazel(pos, LOS)                      [复用 rtklib]
     if el < elmin: continue
     P = prange(nav, obs, i)                         [复用 rtklib]
     dion = ionmodel(obs.t, pos, az, el, nav.ion)    [复用 rtklib]
     trop_hs, trop_wet, _ = tropmodel(obs.t, pos, el, REL_HUMI)  [复用 rtklib]
     mapfh, mapfw = tropmapf(obs.t, pos, el)         [复用 rtklib]
     dtrp = mapfh·trop_hs + mapfw·trop_wet
     v[nv] = P − (r + x[clk] − c·dts[i] + dion + dtrp)
     H[nv, pos:pos+3] = LOS
     H[nv, clk] = 1
     (按卫星系统追加 clk_glo / clk_gal)
     R[nv, nv] = varerr(nav, sys, el, ...)
     nv += 1
5. TcEstimator.tc_meas_update(v, H, R)               [调用 joseph_update]
```

### 5.2 RTK-INS TC（双差载波 + 伪距）

参考 GREAT-MSF `t_gintegration._merge_pose` + GINav `rtkins` / `ddres_rtkins`。

#### 5.2.1 双差量测方程

```
双差观测方程 (流动站 r, 基站 b, 参考星 i, 非参考星 j):
  DD_obs = (y_i^r − y_i^b) − (y_j^r − y_j^b)

  载波相位: y = λ·φ = r + λ·N − dion·λ²/λ_L1² + dtrp + ε_φ
  伪距:     y = P = r + dtr − c·dts + dion + dtrp + ε_P

双差消除了接收机钟差 dtr 和卫星钟差 dts。

双差残差 (量测减预测):
  载波: v_φ = (φ_i^r·λ_i − φ_i^b·λ_i) − (φ_j^r·λ_j − φ_j^b·λ_j)
              − (r_i^r − r_i^b) + (r_j^r − r_j^b)        [几何双差]
              + (dion_i − dion_j)·(λ/λ_L1)²              [电离层, 短基线可忽略]
              − (dtrp_i − dtrp_j)                        [对流层, 短基线可忽略]
              − (λ_i·N_i − λ_j·N_j)                      [模糊度]

  伪距: v_P = (P_i^r − P_i^b) − (P_j^r − P_j^b)
              − (r_i^r − r_i^b) + (r_j^r − r_j^b)
              − (dion_i − dion_j)
              − (dtrp_i − dtrp_j)

其中:
  r_i^r = |sat_i − rcv_r|             流动站到卫星 i 的几何距离 (INS 推算)
  r_i^b = |sat_i − rcv_b|             基站到卫星 i 的几何距离 (基站已知位置)
  N_i, N_j = 双差模糊度 (状态参数)
```

#### 5.2.2 H 矩阵（双差，ECEF）

```
H 矩阵 (对应 δx = est − true 约定, ECEF):

  位置偏导 (参考 GINav ddres_rtkins L74-76):
    H[si.pos : si.pos+3] = LOS_i − LOS_j

    推导: DD_r = (r_i^r − r_i^b) − (r_j^r − r_j^b)
          ∂DD_r/∂rcv_r = ∂r_i^r/∂rcv_r − ∂r_j^r/∂rcv_r = (−LOS_i) − (−LOS_j) = LOS_j − LOS_i
          但 δx = est − true, ∂r/∂δp = −∂r/∂p = LOS
          所以 H_pos = LOS_i − LOS_j  (注意: 与 rtklib ddres 的 H[0:3]=−eu[i]+er[j] 一致)

  姿态偏导 (杆臂效应, 参考 GINav ddres_rtkins L74):
    lever_e = state.C_b_e @ ins_cfg.leverarm          杆臂在 ECEF 的表示
    H[si.att : si.att+3] = (LOS_i − LOS_j) @ askew(lever_e)

    推导: 天线相位中心 = rcv + C_b_e·lever
          ∂r/∂ψ = ∂r/∂(C_b_e·lever)·∂(C_b_e·lever)/∂ψ
                 = (−LOS)·(−askew(lever_e)) = LOS·askew(lever_e)
          双差: H_att = (LOS_i − LOS_j)·askew(lever_e)

  模糊度偏导 (仅载波相位, 参考 rtklib ddres L344-345):
    H[amb_idx(sat_i, freq)] = λ_i      (+1)
    H[amb_idx(sat_j, freq)] = −λ_j     (−1)

  速度偏导 (多普勒双差, 可选):
    H[si.vel : si.vel+3] = LOS_i − LOS_j   (与位置相同, 因 ∂ṙ/∂v = ∂r/∂v = −LOS)

  注意: 双差消除了钟差, H 中无 clk_bias 项
```

#### 5.2.3 R 矩阵（双差）

```
R 矩阵 (参考 rtklib ddcov):
  双差观测噪声 = SD_rover + SD_base (单差方差相加)
  R[k, k] = varerr(nav, sys, el_i, f, ...) + varerr(nav, sys, el_j, f, ...)

  不同卫星间的协方差由双差组合方式决定 (参考 rtklib ddcov 函数)
```

### 5.3 RTD-INS TC（双差伪距）

RTD-INS 与 RTK-INS 的区别：仅使用双差伪距，不使用载波相位，因此**无模糊度参数**。

```
量测方程 (仅伪距双差):
  v_P = (P_i^r − P_i^b) − (P_j^r − P_j^b) − (r_i^r − r_i^b) + (r_j^r − r_j^b) − (dtrp_i − dtrp_j)

H 矩阵:
  H[si.pos : si.pos+3] = LOS_i − LOS_j       (位置)
  H[si.att : si.att+3] = (LOS_i − LOS_j)·askew(lever_e)  (姿态, 若有杆臂)
  (无模糊度项, 无钟差项)

状态向量:
  仅 INS 15 维 (+ 可选块), 无 GNSS 参数块
  TcStateIndex.from_config(config, mode="rtd") → dim = 15 + 可选块

优势: 无需模糊度初始化与固定, 收敛快
劣势: 精度低于 RTK-INS (伪距噪声大于载波)
```

## 6. H 矩阵构造详解

### 6.1 H 矩阵组装规则

```
H 矩阵维度: (n_obs, tc_si.dim)
  n_obs = 量测数 (伪距 + 多普勒, 或 双差载波 + 双差伪距)
  tc_si.dim = INS 维度 + GNSS 参数维数

组装顺序 (列对应 TcStateIndex):
  [pos(3), vel(3), att(3), gyro_bias(3), accel_bias(3), 可选块, clk_bias(4), ambiguity(N)]

SPP-INS H 矩阵示例 (4 颗卫星, 伪距 + 多普勒):
         pos    vel    att    bg    ba    clk
  P_1  [ LOS_1   0      0      0     0     1    ]
  P_2  [ LOS_2   0      0      0     0     1    ]
  P_3  [ LOS_3   0      0      0     0     1    ]
  P_4  [ LOS_4   0      0      0     0     1    ]
  D_1  [  0     -LOS_1  0      0     0     0    ]
  D_2  [  0     -LOS_2  0      0     0     0    ]
  D_3  [  0     -LOS_3  0      0     0     0    ]
  D_4  [  0     -LOS_4  0      0     0     0    ]

RTK-INS H 矩阵示例 (参考星 i, 非参考星 j1/j2, 载波+伪距):
         pos          vel    att              bg    ba    N_i   N_j1   N_j2
  φ_j1 [ LOS_i-LOS_j1  0     ΔLOS·askew(l)    0     0     λ_i   -λ_j1   0   ]
  φ_j2 [ LOS_i-LOS_j2  0     ΔLOS·askew(l)    0     0     λ_i    0    -λ_j2  ]
  P_j1 [ LOS_i-LOS_j1  0     ΔLOS·askew(l)    0     0     0      0      0    ]
  P_j2 [ LOS_i-LOS_j2  0     ΔLOS·askew(l)    0     0     0      0      0    ]

  其中 ΔLOS = LOS_i − LOS_j, l = lever_e = C_b_e @ leverarm
```

### 6.2 杆臂处理

```
杆臂 (lever arm) 定义:
  ins_cfg.leverarm: IMU 中心到 GNSS 天线相位中心的向量 (b 系, FRD)

ECEF 下的杆臂:
  lever_e = state.C_b_e @ ins_cfg.leverarm

天线相位中心位置:
  rcv_antenna = state.pos_e + lever_e

量测方程中的位置:
  SPP-INS: 用 rcv_antenna 计算 r 和 LOS
    r = |sat − rcv_antenna| = |sat − (pos_e + lever_e)|
    LOS = (sat − rcv_antenna) / |sat − rcv_antenna|

  RTK-INS: 双差用 rcv_antenna
    H_pos 仍对应 state.pos_e (IMU 位置), 通过链式法则:
      ∂r/∂pos_e = ∂r/∂rcv_antenna · ∂rcv_antenna/∂pos_e = (−LOS)·I = −LOS
      (δx=est−true, H_pos = LOS)
    H_att 通过杆臂姿态耦合:
      ∂r/∂ψ = LOS · askew(lever_e)

杆臂是否估计:
  若 StateIndex.has_lever_arm(): 杆臂作为状态参数, H 中增加 lever_arm 列
    H[si.lever_arm : si.lever_arm+3] = LOS · C_b_e   (SPP)
    H[si.lever_arm : si.lever_arm+3] = (LOS_i − LOS_j) · C_b_e   (RTK 双差)
  否则: 杆臂为已知常数, 不在 H 中出现
```

### 6.3 杆臂参数配置策略（四种情况）

杆臂参数的处理方式由两个配置项共同决定：
- `ins.leverarm`: 杆臂值 `[x, y, z]`（b 系, FRD, 米），`[0,0,0]` 表示未提供
- `ins.estimate_leverarm`: 是否在线估计杆臂参数（0=不估计 / 1=估计）

四种组合对应不同的滤波器配置：

| 情况 | `leverarm` | `estimate_leverarm` | 处理方式 | 状态向量 | H 矩阵 | 初始值 / 初始 P |
|:---:|:---:|:---:|---|---|---|---|
| **1. 固定杆臂** | ≠ 0 | 0 | 杆臂作为已知常数参与计算，不进入状态向量 | 无 lever_arm 块 | 不含 lever_arm 列 | — |
| **2. 在线估计（有初值）** | ≠ 0 | 1 | 杆臂进入状态向量，初值=配置值，在线维护更新 | 有 lever_arm 块(3维) | 含 lever_arm 列 | x₀=leverarm, P₀=0.1²（小初值，信任配置） |
| **3. 在线估计（无初值）** | = 0 | 1 | 杆臂进入状态向量，初值=0，纯在线估计 | 有 lever_arm 块(3维) | 含 lever_arm 列 | x₀=0, P₀=1.0²（大初值，不确定） |
| **4. 无杆臂** | = 0 | 0 | IMU 与 GNSS 天线视作重合，不考虑杆臂效应 | 无 lever_arm 块 | 不含 lever_arm 列 | leverarm=0 |

**情况详解**：

**情况 1（固定杆臂）**：用户通过外部测量（如卷尺/三维扫描）获得精确杆臂值，不需要滤波器估计。杆臂作为常数参与量测方程构造（`rcv_antenna = pos_e + C_b_e @ leverarm`），但不进入状态向量，H 矩阵不含 lever_arm 列。适用于杆臂已知且安装稳固的场景。

**情况 2（在线估计，有初值）**：用户提供杆臂初值（可能不精确），同时希望滤波器在线精化。杆臂进入状态向量，初始协方差设为较小值（如 0.1² m²），表示对配置值有一定信任。适用于杆臂大致已知但可能随安装松动微变的场景。

**情况 3（在线估计，无初值）**：用户未提供杆臂值，完全依赖滤波器估计。杆臂进入状态向量，初始值为 0，初始协方差设为较大值（如 1.0² m²），表示初始高度不确定。适用于杆臂未知或安装位置不固定的场景。需注意：纯在线估计杆臂的可观测性较弱，通常需要车辆机动（转弯）才能收敛。

**情况 4（无杆臂）**：IMU 与 GNSS 天线物理上非常接近（杆臂 < 1cm），杆臂效应可忽略。量测方程中 `leverarm = 0`，等效于不考虑杆臂。适用于 IMU 与 GNSS 天线集成一体化的设备。

**配置决策树**：

```
读取 ins.leverarm 与 ins.estimate_leverarm
  │
  ├─ leverarm ≠ [0,0,0]?
  │   ├─ Yes, estimate_leverarm = 0 → 情况1: 固定杆臂
  │   │     si.lever_arm = -1 (不进入状态向量)
  │   │     state.leverarm = config.leverarm (常数)
  │   │
  │   └─ Yes, estimate_leverarm = 1 → 情况2: 在线估计(有初值)
  │         si.lever_arm = idx (进入状态向量)
  │         x[si.lever_arm:si.lever_arm+3] = config.leverarm
  │         P[si.lever_arm:si.lever_arm+3, ...] = 0.1² · I
  │
  └─ leverarm == [0,0,0]?
      ├─ Yes, estimate_leverarm = 1 → 情况3: 在线估计(无初值)
      │     si.lever_arm = idx (进入状态向量)
      │     x[si.lever_arm:si.lever_arm+3] = 0
      │     P[si.lever_arm:si.lever_arm+3, ...] = 1.0² · I
      │
      └─ Yes, estimate_leverarm = 0 → 情况4: 无杆臂
            si.lever_arm = -1 (不进入状态向量)
            state.leverarm = [0,0,0] (常数)
```

> **注**：情况 1 与情况 4 在 StateIndex 层面一致（`has_lever_arm() = False`），区别仅在于 `state.leverarm` 常数值不同（情况 1 为配置值，情况 4 为 0）。量测方程构造时统一使用 `state.leverarm`，无需区分。

### 6.4 符号约定汇总

```
本项目误差状态约定: δx = x_est − x_true (估计值减真值)
反馈: state -= δx  (state.pos_e -= delta_pos, state.vel_e -= delta_vel, ...)

量测残差: v = z_obs − h(x_est)  (观测值减预测值)
H 矩阵: H = ∂h/∂x 在 x_est 处, 但需转换到 δx 坐标

转换规则 (δx = est − true):
  h(x_est) = h(x_true + δx) ≈ h(x_true) + ∂h/∂x · δx
  v = z − h(x_est) = z − h(x_true) − ∂h/∂x · δx = v_0 − H_std · δx
  joseph_update 中 innov = Z − H · x, 需 innov = v_0
  所以 Z = v, H = −H_std = −∂h/∂x

  即: 本项目 H = −∂h/∂x (标准偏导的负数)

验证 (位置量测, LcEstimator.meas_update_pos):
  h(pos) = pos, ∂h/∂pos = I, H = −I
  Z = state.pos_e − gnss.position = pos_est − pos_gnss
  innov = Z − H·δpos = (pos_est − pos_gnss) − (−I)·δpos = pos_est − pos_gnss + δpos
       = pos_est − pos_gnss + (pos_est − pos_true) = 2·pos_est − pos_true − pos_gnss
  这不对... 应该是 pos_true − pos_gnss

重新推导 (参考 LcEstimator.feedback: new_pos = state.pos_e − delta_pos):
  δpos = pos_est − pos_true (因为反馈后 new_pos = pos_est − δpos → pos_true)
  Z = pos_est − pos_gnss
  H = I (LcEstimator 中 H[:, pos] = I, 不是 −I)
  innov = Z − H·δpos = (pos_est − pos_gnss) − (pos_est − pos_true) = pos_true − pos_gnss ✓

所以位置量测: H = +I = +∂h/∂pos (不是 −∂h/∂x)

伪距量测:
  h = r(pos) + dtr − ...
  ∂h/∂pos = ∂r/∂pos = −LOS
  按位置量测的规律 H = +∂h/∂pos = −LOS?

  验证: v = P − h(pos_est), Z = v
  innov = v − H·δpos = (P − h(pos_est)) − (−LOS)·δpos
  h(pos_est) ≈ h(pos_true) + (−LOS)·δpos
  v = P − h(pos_true) + LOS·δpos = v_0 + LOS·δpos
  innov = v_0 + LOS·δpos − (−LOS)·δpos = v_0 + 2·LOS·δpos  ✗

  应该 H = +LOS:
  innov = v_0 + LOS·δpos − LOS·δpos = v_0 ✓

  所以伪距 H_pos = +LOS (与 ∂r/∂pos = −LOS 相反)

结论 (本项目 δx = est − true 约定):
  位置量测 (h=pos):        H_pos = +I       (= +∂h/∂pos)
  伪距量测 (h=r+dtr+...):  H_pos = +LOS     (= −∂h/∂pos, 因为 ∂r/∂pos=−LOS)
  速度量测 (h=vel):        H_vel = +I
  多普勒量测 (h=−LOS·v):   H_vel = +LOS     (= −∂h/∂v, 因为 ∂(−LOS·v)/∂v=−LOS)
  双差位置:                H_pos = LOS_i − LOS_j  (= −∂DD_r/∂pos)
```

> **重要**：H 矩阵的符号取决于 `δx` 的定义方向。本项目 `δx = est − true`，因此 `H = −∂h/∂x`（标准偏导的负数）。这与 GINav 的约定一致（GINav `sppins_feedback` 中 `ins.pos = ins.pos − x_fb(7:9)` 表明 `x_fb = est − true`）。

## 8. TcEstimator 类设计

### 8.1 类定义

```python
# src/core/tc/tc_estimator.py
import numpy as np
from src.core.ins.lc_estimator import LcEstimator
from src.core.ins.state_index import StateIndex
from src.core.tc.tc_state_index import TcStateIndex
from src.core.tc.tc_residuals import TcResiduals, ResidualSnapshot


class TcEstimator(LcEstimator):
    """紧组合 EKF 估计器（继承 LcEstimator，扩展 GNSS 参数块）。

    参考:
      - GREAT-MSF t_gsinskf (INS+GNSS 统一滤波)
      - GINav sppins_filter (联合状态更新)
      - 本项目 LcEstimator (复用 time_update / joseph_update / feedback)

    扩展点:
      - 状态向量增加 clk_bias (SPP) / ambiguity (RTK)
      - P 矩阵扩展到 tc_si.dim
      - feedback 增加 GNSS 参数反馈
      - 模糊度预测 (零均值随机游走)
      - **残差输出接口**: tc_meas_update 内部记录先验/后验残差快照
      - **抗差估计预留**: 可选注入 RobustEstimator 调整 R (暂不启用)
      - **降级支持**: 提供 switch_mode 切换量测构造器, reboot 保留随机游走参数
      - **杆臂四种配置**: 根据 leverarm + estimate_leverarm 决定杆臂处理方式 (见 §6.3)
    """

    def __init__(self, state, P, config, mode: str = "spp"):
        # 先调用父类初始化 (INS 15 维 + 可选块)
        super().__init__(state, P, config)
        # 杆臂参数配置策略 (见 §6.3, 四种情况)
        # 需在 TcStateIndex 构建前处理, 因为 estimate_leverarm 的生效条件
        # 不仅取决于配置开关, 还取决于 leverarm 是否非零
        ins_cfg = config.get("ins", {})
        leverarm_cfg = np.array(ins_cfg.get("leverarm", [0.0, 0.0, 0.0]))
        estimate_leverarm_cfg = int(ins_cfg.get("estimate_leverarm", 0))
        leverarm_nonzero = np.any(np.abs(leverarm_cfg) > 1e-6)

        # 根据四种情况调整 estimate_leverarm 配置 (传给 TcStateIndex.from_config)
        # 情况1: leverarm≠0 + 不估计 → estimate_leverarm=0, state.leverarm=leverarm_cfg
        # 情况2: leverarm≠0 + 估计   → estimate_leverarm=1, x[lever_arm]=leverarm_cfg, P=0.1²
        # 情况3: leverarm=0 + 估计   → estimate_leverarm=1, x[lever_arm]=0, P=1.0²
        # 情况4: leverarm=0 + 不估计 → estimate_leverarm=0, state.leverarm=0
        if not leverarm_nonzero and not estimate_leverarm_cfg:
            # 情况4: 无杆臂, 强制 estimate_leverarm=0
            ins_cfg["estimate_leverarm"] = 0
        # 记录杆臂配置情况 (供量测方程构造使用)
        self.leverarm_config = {
            "leverarm": leverarm_cfg,
            "estimate": estimate_leverarm_cfg and (
                leverarm_nonzero or estimate_leverarm_cfg
            ),
            "nonzero": leverarm_nonzero,
            "case": self._classify_leverarm_case(leverarm_nonzero, estimate_leverarm_cfg),
        }

        # 替换 StateIndex 为 TcStateIndex
        self.si = TcStateIndex.from_config(config, mode=mode)
        self.mode = mode
        # 扩展 P 矩阵到 tc_si.dim
        if self.si.dim > self.P.shape[0]:
            old_dim = self.P.shape[0]
            new_P = np.zeros((self.si.dim, self.si.dim))
            new_P[:old_dim, :old_dim] = self.P
            # GNSS 参数初始协方差
            if self.si.has_clk_bias():
                new_P[self.si.clk_bias, self.si.clk_bias] = 100.0**2  # 钟差 100m
                new_P[self.si.clk_bias+1, self.si.clk_bias+1] = 100.0**2
                new_P[self.si.clk_bias+2, self.si.clk_bias+2] = 100.0**2
                new_P[self.si.clk_bias+3, self.si.clk_bias+3] = 100.0**2
            self.P = new_P
        # 扩展 x 向量
        self.x = np.zeros(self.si.dim)
        # 杆臂参数初始化 (情况2/3: 杆臂在状态向量中)
        if self.si.has_lever_arm():
            if leverarm_nonzero:
                # 情况2: 在线估计(有初值), 信任配置值, 小初始 P
                self.x[self.si.lever_arm:self.si.lever_arm+3] = leverarm_cfg
                for i in range(3):
                    self.P[self.si.lever_arm+i, self.si.lever_arm+i] = 0.1**2
            else:
                # 情况3: 在线估计(无初值), 大初始 P
                self.x[self.si.lever_arm:self.si.lever_arm+3] = 0.0
                for i in range(3):
                    self.P[self.si.lever_arm+i, self.si.lever_arm+i] = 1.0**2
        else:
            # 情况1/4: 杆臂不进入状态向量, 作为常数存入 state
            # 情况1: state.leverarm = leverarm_cfg (非零)
            # 情况4: state.leverarm = [0,0,0]
            state.leverarm = leverarm_cfg if leverarm_nonzero else np.zeros(3)
        # 模糊度管理
        if mode == "rtk":
            from src.core.tc.tc_ambiguity import TcAmbiguity
            self.ambiguity = TcAmbiguity(config)
        else:
            self.ambiguity = None
        # 残差输出接口 (先验/后验残差 + H/R/P 快照)
        self.residuals = TcResiduals(config)
        # 抗差估计器 (预留, 默认 None, 不调用)
        self._robust_estimator = None

    def set_robust_estimator(self, robust):
        """注入抗差估计器 (src/core/robust/RobustEstimator)。

        当前预留, 不调用。待 robust 模块实现后:
          robust.adjust_R(v_prior, H, R, P) → R_new
          tc_meas_update 内部用 R_new 替代 R
        """
        self._robust_estimator = robust

    def time_update(self, imu):
        """IMU 机械编排 + P 传播 (复用 LcEstimator.time_update)。

        GNSS 参数 (钟差/模糊度) 在时间更新中:
          - 钟差: 随机游走 (P[clk,clk] += Q_clk·dt)
          - 模糊度: 常数 (P[amb,amb] 不变, 或微弱随机游走)
        """
        super().time_update(imu)
        # 钟差随机游走
        if self.si.has_clk_bias():
            dt = imu.timestamp - self.ins_update._prev_timestamp
            q_clk = (1.0 * dt) ** 2  # 钟差随机游走 PSD
            for i in range(3):
                self.P[self.si.clk_bias+i, self.si.clk_bias+i] += q_clk
        # 模糊度: 常数, 无需处理

    def tc_meas_update(self, v: np.ndarray, H: np.ndarray, R: np.ndarray,
                       innov_clip: float = 0.0,
                       source: str = "gnss") -> None:
        """紧组合量测更新 (复用 joseph_update)。

        Args:
            v: 量测残差 (n_obs,) — 先验残差/新息向量 (z - h(x_est))
            H: 量测矩阵 (n_obs, tc_si.dim)
            R: 量测噪声协方差 (n_obs, n_obs)
            source: 量测来源 ("gnss" / "nhc" / "zupt" / "zaru"),
                    用于残差输出分类与抗差估计策略选择
        """
        # === 1. 先验残差快照 (更新前) ===
        P_prior = self.P.copy()
        x_prior = self.x.copy()
        self.residuals.record_prior(
            source=source,
            v_prior=v.copy(),
            H=H.copy(),
            R=R.copy(),
            P_prior=P_prior,
            x_prior=x_prior,
        )

        # === 2. 抗差估计 (预留, 当前不执行) ===
        # 若注入了 robust_estimator, 用先验残差调整 R
        R_used = R
        if self._robust_estimator is not None:
            R_used = self._robust_estimator.adjust_R(
                v_prior=v, H=H, R=R, P=P_prior, source=source
            )
            self.residuals.record_robust_adjustment(source, R, R_used)

        # === 3. 量测更新 (Joseph form) ===
        Z = v  # 残差即创新 (v = z - h(x_est))
        self.joseph_update(Z, H, R_used, innov_clip)

        # === 4. 后验残差快照 (更新后) ===
        # 后验残差 v_post = v - H · dx (dx = 更新量)
        dx = self.x - x_prior  # 本次更新引起的误差状态变化
        v_post = v - H @ dx
        self.residuals.record_posterior(
            source=source,
            v_posterior=v_post,
            P_posterior=self.P.copy(),
            x_posterior=self.x.copy(),
        )

    def feedback(self):
        """统一反馈 (INS 参数复用 LcEstimator.feedback + GNSS 参数独立反馈)。

        参考:
          - GINav sppins_feedback (INS 闭环校正)
          - GREAT-MSF _gnss_feedback (GNSS 参数反馈)
        """
        # INS 参数反馈 (复用父类)
        super().feedback()
        # GNSS 参数反馈
        if self.si.has_clk_bias():
            # 钟差反馈: 更新 nav.x (若需要输出) 或仅保留在 self.x
            pass  # 钟差通常不反馈到 INS, 仅在 GNSS 量测中使用
        if self.si.has_ambiguity() and self.ambiguity is not None:
            # 模糊度反馈: 更新模糊度状态
            self.ambiguity.apply_correction(self.x[self.si.ambiguity:self.si.ambiguity+self.si.n_amb])
            self.x[self.si.ambiguity:self.si.ambiguity+self.si.n_amb] = 0.0

    # ============= 降级与重启支持 =============
    def switch_mode(self, new_mode: str, measurement_builder) -> None:
        """切换紧组合模式 (RTK→RTD→SPP 降级时调用)。

        Args:
            new_mode: "rtk" / "rtd" / "spp"
            measurement_builder: 新模式对应的 TcMeasurement 实例
        """
        self.mode = new_mode
        # 注意: 状态向量维度可能变化 (rtk 有 ambiguity, spp 无)
        # 由 TcDegradeManager 负责状态向量重整, 此处仅切换量测构造器
        self._measurement_builder = measurement_builder

    def reboot(self, keep_random_walk: bool = True) -> None:
        """重启滤波器 (长期无 GNSS 解算时调用)。

        参考:
          - GINav rebootc (insstate_t 重置)
          - ignav insstate_t 初值

        Args:
            keep_random_walk: 是否保留随机游走类参数估计值
                - True (默认): 保留 gyro_bias / accel_bias / lever_arm / imu_angle
                              这些参数短期内变化缓慢, 重启后保留可加速收敛
                - False: 全部重置为初始值
        """
        if keep_random_walk:
            # 保留随机游走类参数的估计值与协方差
            preserved = {}
            for name, idx, dim in [
                ("gyro_bias", self.si.gyro_bias, 3),
                ("accel_bias", self.si.accel_bias, 3),
                ("lever_arm", self.si.lever_arm, 3 if self.si.has_lever_arm() else 0),
                ("imu_angle", self.si.imu_angle, 2 if self.si.has_imu_angle() else 0),
                ("imu_leverarm", self.si.imu_leverarm, 3 if self.si.has_imu_leverarm() else 0),
            ]:
                if dim > 0:
                    preserved[name] = (self.state_snapshot(idx, dim))
            # 重置 INS 状态 (位置/速度/姿态) — 由 InsInitializer 重新初始化
            # 重置 GNSS 参数 (钟差/模糊度)
            # 恢复保留的随机游走参数
            for name, (val, cov) in preserved.items():
                self.restore_snapshot(name, val, cov)
        else:
            # 全部重置
            pass
        # 模糊度管理器复位
        if self.ambiguity is not None:
            self.ambiguity.reset()

    def state_snapshot(self, idx: int, dim: int):
        """获取状态块快照 (值 + 协方差)。"""
        val = self.x[idx:idx+dim].copy()
        cov = self.P[idx:idx+dim, idx:idx+dim].copy()
        return (val, cov)

    def restore_snapshot(self, name: str, val, cov) -> None:
        """恢复状态块 (值 + 协方差)。"""
        idx = getattr(self.si, name)
        dim = len(val)
        self.x[idx:idx+dim] = val
        self.P[idx:idx+dim, idx:idx+dim] = cov

    @staticmethod
    def _classify_leverarm_case(leverarm_nonzero: bool, estimate: bool) -> int:
        """分类杆臂配置情况 (见 §6.3)。

        Returns:
            1: 固定杆臂 (leverarm≠0, 不估计)
            2: 在线估计有初值 (leverarm≠0, 估计)
            3: 在线估计无初值 (leverarm=0, 估计)
            4: 无杆臂 (leverarm=0, 不估计)
        """
        if leverarm_nonzero:
            return 2 if estimate else 1
        else:
            return 3 if estimate else 4

    def get_leverarm(self) -> np.ndarray:
        """获取当前杆臂值 (b 系, FRD, 米)。

        情况1/4: 返回 state.leverarm (常数)
        情况2/3: 返回 x[si.lever_arm:si.lever_arm+3] (估计值)
        供 TcMeasurement 构造量测方程时使用。
        """
        if self.si.has_lever_arm():
            return self.x[self.si.lever_arm:self.si.lever_arm+3].copy()
        else:
            return self.state.leverarm.copy()
```

```python
class SppTcMeas(TcMeasurement):
    """SPP-INS 紧组合量测构造器（伪距 + 多普勒）。

    参考:
      - ignav pntpos.cc rescode (伪距残差)
      - GINav rescode_sppins (H 矩阵含 INS 位置)
      - rtklib pntpos.py rescode / resdop (可复用的工具逻辑)
    """

    def __init__(self, config: dict):
        self.use_doppler = config.get("ins", {}).get("tc_use_doppler", True)

    def build(self, obs, nav, state, si, x, P):
        from src.core.gnss.rtklib.ephemeris import satposs
        from src.core.gnss.rtklib.rtkcmn import geodist, satazel, ecef2pos, \
            ionmodel, tropmodel, tropmapf, satexclude, sat2prn, uGNSS
        from src.core.gnss.rtklib.pntpos import prange, varerr
        from src.core.gnss.rtklib import rtkcmn as gn
        from src.core.ins.attitude import skew

        # 1. 卫星位置
        rs, dts, svh = satposs(obs, nav, nav.ephover)

        # 2. 接收机位置 (INS 推算 + 杆臂)
        lever_e = state.C_b_e @ nav.leverarm if hasattr(nav, 'leverarm') else np.zeros(3)
        rr = state.pos_e + lever_e
        pos = ecef2pos(rr)

        # 3. 钟差 (从误差状态读取)
        dtr = x[si.clk_bias] if si.has_clk_bias() else 0.0

        ns = len(obs.sat)
        v_list, H_rows, var_list = [], [], []

        for i in range(ns):
            sys = sat2prn(obs.sat[i])[0]
            if np.linalg.norm(rs[i, :3]) < gn.rCST.RE_WGS84:
                continue
            if satexclude(obs.sat[i], 0.0, svh[i], nav):
                continue
            r, LOS = geodist(rs[i, :3], rr)
            if r < 0:
                continue
            az, el = satazel(pos, LOS)
            if el < nav.elmin:
                continue
            P_obs = prange(nav, obs, i)
            if P_obs == 0:
                continue
            dion = ionmodel(obs.t, pos, az, el, nav.ion)
            trop_hs, trop_wet, _ = tropmodel(obs.t, pos, el, 0.7)
            mapfh, mapfw = tropmapf(obs.t, pos, el)
            dtrp = mapfh * trop_hs + mapfw * trop_wet

            # 伪距残差
            v_i = P_obs - (r + dtr - gn.rCST.CLIGHT * dts[i] + dion + dtrp)
            v_list.append(v_i)

            # H 矩阵行
            h_row = np.zeros(si.dim)
            h_row[si.pos:si.pos+3] = LOS          # 位置偏导 (δx=est−true, H=LOS)
            if si.has_clk_bias():
                h_row[si.clk_bias] = 1.0           # 钟差偏导
                if sys == uGNSS.GLO:
                    h_row[si.clk_bias+1] = 1.0
                elif sys == uGNSS.GAL:
                    h_row[si.clk_bias+2] = 1.0
                elif sys == uGNSS.BDS:
                    h_row[si.clk_bias+3] = 1.0
            H_rows.append(h_row)
            var_list.append(varerr(nav, sys, el, nav.rcvstd[obs.sat[i]-1, 0]))

        v = np.array(v_list)
        H = np.array(H_rows)
        R = np.diag(var_list)
        return v, H, R, {"ns": len(v_list)}
```

## 10. TcIntegration 主循环

### 10.1 设计

`TcIntegration` 参考 `LcIntegration` 的 GVINS 风格 IMU 消费，但量测更新从 `GnssSolution`（位置/速度）改为原始观测（伪距/载波）。同时集成**降级策略**（`TcDegradeManager`）与**约束外部化**（`MotionConstraintManager`）。

```python
# src/core/tc/tc_integration.py
import collections
import logging
from typing import Optional
from src.core.data_types import ImuMeasurement
from src.core.ins.interpolator import imu_interpolate_linear
from src.core.tc.tc_degrade import TcDegradeManager, DegradeLevel
from src.core.motion.motion_manager import MotionConstraintManager

logger = logging.getLogger(__name__)


class TcIntegration:
    """紧组合集成（GVINS 风格 IMU 消费 + 原始观测量测触发）。

    参考:
      - 本项目 LcIntegration (GVINS 风格 IMU 消费框架)
      - ignav tcigpos (紧组合主循环)
      - GREAT-MSF t_gintegration._processEpoch (历元处理)

    主循环 (每个新 IMU 到来时):
      1. 检查 pending_obs 队头:
         - obs.t < cur.t: 防御性直接量测更新 (过期观测)
         - cur.t <= obs.t <= imu.t: 线性插值到 obs.t, time_update(interp),
           触发紧组合量测更新 (TcMeasurement.build + tc_meas_update), 弹出 obs
         - obs.t > imu.t: 留给后续 IMU, 跳出循环
      2. 推进当前 IMU: time_update(imu)
      3. 约束更新: 通过 MotionConstraintManager 注入 NHC/ZUPT/ZARU 伪量测

    与 LcIntegration 的区别:
      - pending_gnss (GnssSolution) → pending_obs (obsd_t + nav)
      - _apply_gnss_update (位置量测) → _apply_tc_update (原始观测量测)
      - 内嵌 Constraints → 外部 MotionConstraintManager (松紧组合共用)
      - 新增 TcDegradeManager: 降级策略 + reboot 机制
    """

    def __init__(self, estimator, measurement, config: dict):
        self.est = estimator           # TcEstimator
        self.meas = measurement        # TcMeasurement (当前模式对应的构造器)
        self.config = config

        # 降级管理器 (RTK→RTD→SPP→IMU 机械编排 + reboot)
        self.degrade = TcDegradeManager(config, initial_mode=estimator.mode)
        # 各模式量测构造器缓存 (降级时切换)
        self._meas_builders = {
            "rtk": None, "rtd": None, "spp": None,
        }
        self._meas_builders[estimator.mode] = measurement

        # 约束管理器 (src/core/motion, 松紧组合共用)
        self.motion = MotionConstraintManager(config)
        # 注册约束回调: motion 检测到约束条件时, 通过此回调注入伪量测到主滤波
        self.motion.set_inject_callback(self._inject_constraint)

        self.imupre: Optional[ImuMeasurement] = None
        self.imucur: Optional[ImuMeasurement] = None
        self.pending_obs: collections.deque = collections.deque()  # (obs, nav) 对
        self.last_qins: int = 2

    def add_imu(self, imu: ImuMeasurement) -> None:
        """GVINS 风格 IMU 消费（与 LcIntegration.add_imu 结构一致）。"""
        if self.imucur is None:
            self.imucur = imu
            self.motion.push_imu(imu)  # 约束检测器喂数据
            self.last_qins = 2
            return

        self.last_qins = 2
        cur = self.imucur

        while self.pending_obs:
            obs, nav = self.pending_obs[0]
            t_obs = obs[0].t  # 历元时间 (Unix)

            if t_obs < cur.timestamp:
                self._apply_tc_update(obs, nav)
                self.pending_obs.popleft()
                continue

            if t_obs > imu.timestamp:
                break

            # 插值到 obs.t
            interp = imu_interpolate_linear(cur, imu, t_obs)
            if interp is None:
                break
            self.imupre = cur
            self.imucur = interp
            self.est.time_update(interp)
            self.motion.push_imu(interp)  # 约束检测
            self.motion.apply_constraints(interp, self.est, source_prefix="tc")  # 注入伪量测

            self._apply_tc_update(obs, nav)
            self.pending_obs.popleft()
            cur = interp

        # 推进当前 IMU
        self.imupre = cur
        self.imucur = imu
        self.est.time_update(imu)
        self.motion.push_imu(imu)
        self.motion.apply_constraints(imu, self.est, source_prefix="tc")

        # 降级检查 (每个 IMU 历元)
        self._check_degrade(imu.timestamp)

    def add_obs(self, obs, nav) -> None:
        """添加 GNSS 原始观测 (替代 LcIntegration.add_gnss)。"""
        self.pending_obs.append((obs, nav))

    def _apply_tc_update(self, obs, nav) -> None:
        """紧组合量测更新（替代 LcIntegration._apply_gnss_update）。

        参考 ignav tcigpos L216-232 (调用 rtkpos) 的位置, 但用 TcMeasurement 替代。

        降级处理:
          - 当前模式 RTK: 若模糊度固定失败或卫星数不足, 触发降级到 RTD
          - 当前模式 RTD: 若双差伪距残差过大或卫星数不足, 触发降级到 SPP
          - 当前模式 SPP: 若卫星数 < 4, 触发降级到 IMU 机械编排
          - 降级后仍尝试用新模式构造量测, 若仍失败则跳过 (仅机械编排)
        """
        # 根据当前降级级别选择量测构造器
        cur_mode = self.degrade.current_mode()
        if cur_mode == DegradeLevel.IMU_ONLY:
            # 仅 IMU 机械编排, 无 GNSS 量测
            self.degrade.record_failure(obs[0].t)
            return

        meas_builder = self._get_measurement_builder(cur_mode)
        if meas_builder is None:
            self.degrade.record_failure(obs[0].t)
            return

        v, H, R, info = meas_builder.build(
            obs, nav, self.est.state, self.est.si, self.est.x, self.est.P
        )

        # 量测有效性检查 (卫星数/残差)
        if not self._is_measurement_valid(cur_mode, v, info):
            self.degrade.record_failure(obs[0].t)
            # 尝试降级
            new_mode = self.degrade.try_degrade()
            if new_mode != cur_mode:
                self._switch_mode(new_mode)
            return

        # 量测更新 (TcEstimator 内部记录先验/后验残差)
        self.est.tc_meas_update(v, H, R, source="gnss")
        # 模糊度固定 (仅 RTK 模式)
        if cur_mode == "rtk" and self.est.ambiguity is not None:
            fixed = self.est.ambiguity.try_fix(self.est.x, self.est.P, self.est.si)
            if not fixed and self.degrade.should_degrade_on_amb_fail():
                new_mode = self.degrade.try_degrade()
                if new_mode != cur_mode:
                    self._switch_mode(new_mode)
        self.est.feedback()
        self.degrade.record_success(obs[0].t)
        self.last_qins = 3

    def _inject_constraint(self, v_c, H_c, R_c, source: str) -> None:
        """约束伪量测注入回调 (MotionConstraintManager 调用)。

        Args:
            v_c: 约束伪量测残差
            H_c: 约束伪量测设计矩阵
            R_c: 约束伪量测噪声协方差
            source: "nhc" / "zupt" / "zaru"
        """
        self.est.tc_meas_update(v_c, H_c, R_c, source=source)
        # 约束更新后立即反馈 (per-IMU 节奏)
        self.est.feedback()

    def _check_degrade(self, cur_timestamp: float) -> None:
        """降级状态机检查 (每个 IMU 历元)。

        - 若距上次 GNSS 成功解算时间 > reboot 阈值, 触发 reboot
        - reboot 保留随机游走类参数 (gyro_bias/accel_bias/lever_arm/imu_angle)
        """
        if self.degrade.should_reboot(cur_timestamp):
            logger.warning("TC reboot triggered: no GNSS for %.1f s",
                           self.degrade.reboot_threshold)
            self.est.reboot(keep_random_walk=True)
            self.degrade.reset_after_reboot(cur_timestamp)
            # 重置后回到最高优先级模式 (rtk 或配置的初始模式)
            self._switch_mode(self.degrade.initial_mode)

    def _switch_mode(self, new_mode: str) -> None:
        """切换紧组合模式 (降级或恢复时调用)。"""
        logger.info("TC mode switch: %s → %s", self.degrade.current_mode(), new_mode)
        new_builder = self._get_measurement_builder(new_mode)
        self.est.switch_mode(new_mode, new_builder)

    def _get_measurement_builder(self, mode: str):
        """获取指定模式的量测构造器 (惰性创建)。"""
        if self._meas_builders[mode] is None:
            self._meas_builders[mode] = self._create_measurement(mode)
        return self._meas_builders[mode]

    def _create_measurement(self, mode: str):
        """创建指定模式的量测构造器。"""
        from src.core.tc.tc_measurement import SppTcMeas, RtkTcMeas, RtdTcMeas
        if mode == "spp":
            return SppTcMeas(self.config)
        elif mode == "rtk":
            return RtkTcMeas(self.config)
        elif mode == "rtd":
            return RtdTcMeas(self.config)
        return None  # imu_only

    def _is_measurement_valid(self, mode: str, v: np.ndarray, info: dict) -> bool:
        """量测有效性检查 (降级判断依据)。"""
        ns = info.get("ns", 0)
        min_sat = {"spp": 4, "rtd": 4, "rtk": 5}.get(mode, 4)
        if ns < min_sat:
            return False
        # 可选: 残差大小检查 (max|v| < threshold)
        if len(v) > 0 and np.max(np.abs(v)) > 100.0:  # 100m 残差阈值
            return False
        return True
```

### 11.1 设计

`TcStream` 参考 `LcStream`，但喂入原始观测而非 `GnssSolution`。

```python
# src/core/tc/tc_stream.py
class TcStream:
    """紧组合流式运行器（per-IMU 输出 .rslt）。

    参考:
      - 本项目 LcStream (流式框架)
      - GREAT-MSF processBatchFB (批处理主循环)

    与 LcStream 的区别:
      - feed_gnss(gnss: GnssSolution) → feed_obs(obs, nav)
      - LcEstimator → TcEstimator
      - 量测更新: 位置量测 → 原始观测量测
    """

    def __init__(self, config: dict, writer, mode: str = "spp"):
        self.config = config
        self.writer = writer
        self.mode = mode
        self.initializer = InsInitializer(config)

        # 初始化前缓冲
        self._init_imu = []
        self._init_obs = []
        self._initialized = False
        self._est = None
        self._integ = None
        self._si = None
        self._output_count = 0

    def feed_imu(self, imu: ImuMeasurement) -> None:
        """喂入 IMU（与 LcStream.feed_imu 结构一致）。"""
        if not self._initialized:
            self._init_imu.append(imu)
            if self._init_obs and imu.timestamp >= self._init_obs[-1][0][0].t:
                self._try_init()
            return
        self._integ.add_imu(imu)
        self._write_state(self._integ.last_qins)

    def feed_obs(self, obs, nav) -> None:
        """喂入 GNSS 原始观测（替代 LcStream.feed_gnss）。"""
        if not self._initialized:
            self._init_obs.append((obs, nav))
            return
        self._integ.add_obs(obs, nav)

    def _try_init(self) -> None:
        """初始化（复用 InsInitializer，但用原始观测做 SPP 粗定位）。"""
        # 用首个历元原始观测做 SPP 粗定位获取初始位置
        # 或用外部提供的初始位置
        ...
        # 创建 TcEstimator + TcMeasurement + TcIntegration
        self._est = TcEstimator(init_state, init_P, self.config, mode=self.mode)
        meas = self._create_measurement()
        self._integ = TcIntegration(self._est, meas, self.config)
        self._si = self._est.si
        self._initialized = True
        # 回放缓冲
        self._replay_buffer(init_state.timestamp)
        self._init_imu.clear()
        self._init_obs.clear()

    def _create_measurement(self):
        if self.mode == "spp":
            return SppTcMeas(self.config)
        elif self.mode == "rtk":
            return RtkTcMeas(self.config)
        elif self.mode == "rtd":
            return RtdTcMeas(self.config)
```

```python
# src/stream/tc_gnss_sensor.py
class TcGnssSensor(Thread):
    """紧组合 GNSS 原始观测传感器。

    与 InternalGnssSensor 的区别:
      - 不调用 pntpos/rtkpos 解算
      - 直接输出 (obsd_t[], nav_t) 原始观测
      - 逐历元推进 (first_obs / next_obs)
    """

    def __init__(self, config, output_queue, control):
        Thread.__init__(self, name="TcGnssSensor", daemon=True)
        self.config = config
        self.gnss_cfg = config["gnss"]
        self.output_queue = output_queue
        self.control = control

    def run(self):
        try:
            self._run_impl()
        finally:
            self.output_queue.put(None)  # EOF

    def _run_impl(self):
        env = RtklibEnv(self.gnss_cfg)
        env.setup()
        nav = env.init_nav()

        from src.core.gnss.rtklib import rinex as rn
        rov = rn.rnx_decode(env.get_cfg())
        rov.decode_obsfile(nav, self.gnss_cfg["rover_path"], None)
        rov.decode_nav(self.gnss_cfg["eph_path"], nav)

        base = None
        if self.gnss_cfg.get("positioning_mode") in ("rtk", "rtd"):
            base = rn.rnx_decode(env.get_cfg())
            base.decode_obsfile(nav, self.gnss_cfg["base_path"], None)
            if nav.rb[0] == 0:
                nav.rb = base.pos

        dir = 1
        obsr, obsb = rn.first_obs(nav, rov, base, dir)
        while True:
            if not self.control.is_running():
                break
            if obsr == []:
                break
            # 输出原始观测 (obsr, obsb, nav)
            self.output_queue.put(SensorData(tag="tc_obs",
                                             tc_obs=(obsr, obsb, nav)))
            obsr, obsb = rn.next_obs(nav, rov, base, dir)
```

### 12.3 数据流时序

```
【紧组合模式 internal + ins.enabled=tc】
  ImuSensor.run()
    → imu_queue.put(SensorData(tag="imu"))
        ↓
  TcGnssSensor.run()                     (原始观测, 不解算)
    → obs_queue.put(SensorData(tag="tc_obs", tc_obs=(obsr, obsb, nav)))
        ↓
  Logger                                 (消费 imu_queue + obs_queue)
    → _drain_imu_queue() → tc_stream 缓冲
    → obs_queue.get() → tc_stream.feed_obs(obsr, obsb, nav)
    → 等待 IMU 覆盖 obs.t
    → 按时间顺序喂入 TcStream:
        before IMU (t < obs.t) → tc_stream.feed_imu()
        obs → tc_stream.feed_obs()
        after IMU (t >= obs.t) → tc_stream.feed_imu()  [触发 GVINS 插值 + TC 量测更新]
    → tc_stream 内部:
        TcIntegration.add_imu() 检测 obs.t 落入 [cur.t, imu.t]
        → 插值到 obs.t
        → TcMeasurement.build(obs, nav, ins_state) → (v, H, R)
        → TcEstimator.tc_meas_update(v, H, R)
        → TcEstimator.feedback()
        → per-IMU 写出 .rslt
```

## 13. 模糊度解算

### 13.1 TcAmbiguity 类

```python
# src/core/tc/tc_ambiguity.py
class TcAmbiguity:
    """模糊度状态管理 + LAMBDA 固定。

    参考:
      - rtklib lambda.py resamb_LAMBDA (LAMBDA 算法)
      - GINav resamb_rtkins (模糊度复位/固定)
      - ignav armode (fix-and-hold 策略)
    """

    def __init__(self, config: dict):
        gnss_cfg = config.get("gnss", {})
        self.armode = gnss_cfg.get("armode", 0)  # TC 当前默认关闭 AR；1=continuous, 3=fix-and-hold（待缺陷修复后启用）
        self.thresar = gnss_cfg.get("thresar", 3.0)
        self.thresar1 = gnss_cfg.get("thresar1", 0.5)  # posvar 阈值
        self.minfix = gnss_cfg.get("minfix", 10)
        self.nfix = 0
        self.amb_state = False  # 是否已固定
        self.ratio = 0.0

    def try_fix(self, x, P, si: TcStateIndex) -> bool:
        """尝试 LAMBDA 模糊度固定。

        Returns:
            True if fixed, False if float
        """
        if not si.has_ambiguity() or si.n_amb < 4:
            return False
        # 检查 posvar (参考 ignav thresar1)
        posvar = np.sum(np.diag(P[si.pos:si.pos+3, si.pos:si.pos+3])) / 3.0
        if posvar > self.thresar1:
            return False
        # 提取模糊度子块
        amb_idx = si.ambiguity
        n = si.n_amb
        xa = x[amb_idx:amb_idx+n].copy()
        Pa = P[amb_idx:amb_idx+n, amb_idx:amb_idx+n].copy()
        # 调用 rtklib LAMBDA
        from src.core.gnss.rtklib.lambda_py import resamb_LAMBDA
        xa_fixed, ratio = resamb_LAMBDA(xa, Pa, n)
        self.ratio = ratio
        if ratio >= self.thresar:
            x[amb_idx:amb_idx+n] = xa_fixed
            self.amb_state = True
            self.nfix += 1
            if self.armode == 3 and self.nfix >= self.minfix:
                self._hold_ambiguity(x, P, xa_fixed, amb_idx, n)
            return True
        self.amb_state = False
        return False

    def apply_correction(self, delta_amb):
        """应用反馈校正到模糊度状态。"""
        self.amb_values += delta_amb  # 若维护独立模糊度值

    def _hold_ambiguity(self, x, P, xa_fixed, amb_idx, n):
        """fix-and-hold: 固定后约束 P。"""
        for i in range(n):
            P[amb_idx+i, amb_idx+i] = 1e-6  # 强约束
```

## 14. 初始化与对齐

### 14.1 紧组合初始化流程

```
紧组合初始化 (TcStream._try_init):

  1. 等待 IMU + 原始观测就绪 (包夹条件)
  2. 用首个历元原始观测做 SPP 粗定位 (仅初始化用, 复用 pntpos.estpos)
     → 获取初始位置 rr (ECEF)
  3. 调用 InsInitializer.initialize(block, mode) 获取 InsState + init_P
     (复用松组合的初始化, 参考 skills/初始化.md)
  4. 创建 TcEstimator(state, init_P, config, mode)
  5. 创建 TcMeasurement (SppTcMeas / RtkTcMeas / RtdTcMeas)
  6. 创建 TcIntegration(estimator, measurement, config)
  7. 回放缓冲中 init 时间戳之后的事件
```

### 14.2 与松组合初始化的差异

| 维度 | 松组合 | 紧组合 |
|------|--------|--------|
| 初始位置来源 | `GnssSolution.position` (已解算) | 原始观测做 SPP 粗定位 (pntpos.estpos) |
| 初始化模块 | `InsInitializer` | `InsInitializer` (复用) + pntpos.estpos (初始位置) |
| 初始 P | `InsInitializer` 提供 | `InsInitializer` 提供 + GNSS 参数初始 P (TcEstimator 扩展) |
| 模式 | 静态 / 速度矢量 / 位置差分 | 相同 (复用) |

> **注意**：紧组合初始化时，INS 部分（姿态/速度/位置/零偏）完全复用 `InsInitializer`。GNSS 参数（钟差/模糊度）的初始 P 在 `TcEstimator.__init__` 中设置。

## 16. 降级策略与重启机制

### 16.1 设计目标

紧组合在 GNSS 信号质量下降或 INS 长时间无 GNSS 量测更新时，按以下顺序降级保证输出连续性，并在持续不可解算时执行 reboot（保留随机游走类参数）：

```
RTK-INS (双差载波+伪距, 模糊度固定)
  │  模糊度固定失败 / 卫星数 < 5 / 残差过大
  ▼
RTD-INS (双差伪距, 无模糊度)
  │  卫星数 < 4 / 双差伪距残差过大
  ▼
SPP-INS (零差伪距+多普勒)
  │  卫星数 < 4
  ▼
IMU 机械编排 (无 GNSS 量测, 仅 time_update + 约束)
  │  持续无 GNSS > reboot_threshold (默认 30s)
  ▼
REBOOT (重启滤波器, 保留随机游走参数, 回到初始模式)
```

### 16.2 TcDegradeManager 类设计

```python
# src/core/tc/tc_degrade.py
import logging
from enum import Enum
from typing import Optional

logger = logging.getLogger(__name__)


class DegradeLevel(str, Enum):
    """降级级别 (字符串枚举, 便于配置与日志)。"""
    RTK = "rtk"          # 双差载波 + 伪距, 模糊度固定
    RTD = "rtd"          # 双差伪距, 无模糊度
    SPP = "spp"          # 零差伪距 + 多普勒
    IMU_ONLY = "imu"     # 仅 IMU 机械编排


# 降级链 (从高到低)
DEGRADE_CHAIN = [
    DegradeLevel.RTK, DegradeLevel.RTD, DegradeLevel.SPP, DegradeLevel.IMU_ONLY
]


class TcDegradeManager:
    """降级状态机 + reboot 计时器。

    参考:
      - GINav rebootc (insstate_t 重置, 保留部分参数)
      - ignav insstate_t (reboot 标志与重置策略)
      - 本项目 project_memory: 长时间无 GNSS 观测需重新初始化

    职责:
      - 维护当前降级级别
      - 记录最近一次 GNSS 成功解算时间
      - 连续失败时按 DEGRADE_CHAIN 降级
      - 超过 reboot_threshold 时触发 reboot (保留随机游走参数)
      - GNSS 恢复时按恢复策略升级 (可选: 直接到 RTK 或逐级升级)
    """

    def __init__(self, config: dict, initial_mode: str = "rtk"):
        tc_cfg = config.get("tc", {})
        degrade_cfg = tc_cfg.get("degrade", {})
        self.initial_mode = initial_mode
        self._level = initial_mode
        # 各模式最少卫星数 (降级判断依据)
        self.min_sats = degrade_cfg.get("min_sats", {
            "rtk": 5, "rtd": 4, "spp": 4
        })
        # 降级触发: 连续失败次数
        self.fail_threshold = degrade_cfg.get("fail_threshold", 3)
        self._fail_count = 0
        # reboot 阈值: 距上次成功 GNSS 解算的秒数
        self.reboot_threshold = degrade_cfg.get("reboot_threshold", 30.0)
        # 模糊度固定失败是否触发降级 (RTK→RTD)
        self.degrade_on_amb_fail = degrade_cfg.get("degrade_on_amb_fail", True)
        # 恢复策略: "direct" (直接回 initial_mode) / "step" (逐级升级)
        self.recover_strategy = degrade_cfg.get("recover_strategy", "direct")
        # 时间戳
        self._last_success_time: Optional[float] = None
        self._cur_time: Optional[float] = None

    def current_mode(self) -> str:
        return self._level

    def record_success(self, timestamp: float) -> None:
        """记录 GNSS 成功解算。"""
        self._last_success_time = timestamp
        self._cur_time = timestamp
        self._fail_count = 0
        # 若当前处于降级状态, 触发恢复
        if self._level != self.initial_mode:
            self._try_recover()

    def record_failure(self, timestamp: float) -> None:
        """记录 GNSS 解算失败。"""
        self._cur_time = timestamp
        self._fail_count += 1

    def try_degrade(self) -> str:
        """尝试降级一级 (连续失败达阈值时调用)。

        Returns:
            新的降级级别 (若未降级返回当前级别)
        """
        if self._fail_count < self.fail_threshold:
            return self._level
        cur_idx = DEGRADE_CHAIN.index(self._level) if self._level in DEGRADE_CHAIN else 0
        if cur_idx >= len(DEGRADE_CHAIN) - 1:
            # 已到最低级 (IMU_ONLY)
            self._level = DegradeLevel.IMU_ONLY
            return self._level
        new_level = DEGRADE_CHAIN[cur_idx + 1]
        logger.warning("TC degrade: %s → %s (fail_count=%d)",
                       self._level, new_level, self._fail_count)
        self._level = new_level
        self._fail_count = 0  # 降级后重置计数, 给新模式机会
        return self._level

    def should_degrade_on_amb_fail(self) -> bool:
        """RTK 模糊度固定失败是否触发降级。"""
        return self.degrade_on_amb_fail and self._level == DegradeLevel.RTK

    def should_reboot(self, cur_timestamp: float) -> bool:
        """是否触发 reboot (长期无 GNSS 量测)。"""
        self._cur_time = cur_timestamp
        if self._last_success_time is None:
            # 从未成功过, 用启动时间作为基准 (由 TcStream 注入)
            return False
        gap = cur_timestamp - self._last_success_time
        return gap > self.reboot_threshold

    def reset_after_reboot(self, cur_timestamp: float) -> None:
        """reboot 后重置状态。"""
        self._level = self.initial_mode
        self._fail_count = 0
        self._last_success_time = cur_timestamp  # 重置计时基准

    def _try_recover(self) -> None:
        """GNSS 恢复时升级模式。"""
        if self.recover_strategy == "direct":
            self._level = self.initial_mode
            logger.info("TC recover: → %s (direct)", self._level)
        else:  # step
            cur_idx = DEGRADE_CHAIN.index(self._level)
            if cur_idx > 0:
                new_level = DEGRADE_CHAIN[cur_idx - 1]
                logger.info("TC recover: %s → %s (step)", self._level, new_level)
                self._level = new_level
```

### 16.3 reboot 保留的随机游走参数

参考 [project_memory](file:///home/mxl/.trae-cn/memory/projects/-home-mxl-workplace-gipylib/project_memory.md) 中"初始化需识别 reboot"约束。reboot 时保留以下随机游走类参数（短期内变化缓慢，重启后保留可加速收敛）：

| 参数 | 索引 | 维数 | 保留理由 |
|------|------|------|---------|
| `gyro_bias` | `si.gyro_bias` | 3 | 陀螺零偏随机游走缓慢，重启后保留可避免重新标定 |
| `accel_bias` | `si.accel_bias` | 3 | 加计零偏同上 |
| `lever_arm` | `si.lever_arm` | 3 (可选) | IMU→GNSS 天线杆臂物理常数，不随重启变化 |
| `imu_angle` | `si.imu_angle` | 2 (可选) | IMU 安装角物理常数 |
| `imu_leverarm` | `si.imu_leverarm` | 3 (可选) | IMU 杆臂物理常数 |

**重置的参数**：
- `pos / vel / att`：由 `InsInitializer` 用首个有效 GNSS 历元重新初始化
- `clk_bias`：GNSS 钟差，重置为 0，P 重置为大初值（100m）
- `ambiguity`：双差模糊度，全部复位（卫星几何可能已变化）
- `time_sync`：时间对齐误差，重置为 0

### 16.4 降级时的状态向量重整

不同模式的状态向量维度不同：
- RTK: INS(15+可选) + ambiguity(N)
- RTD: INS(15+可选) — 无 GNSS 参数
- SPP: INS(15+可选) + clk_bias(4)

降级/升级时由 `TcEstimator.switch_mode` 配合 `TcStateIndex.from_config(config, mode=new_mode)` 重建状态索引，保留 INS 部分与随机游走参数，丢弃或新增 GNSS 参数块：

```python
# 降级时的状态向量重整 (伪代码)
def switch_mode(self, new_mode, measurement_builder):
    old_si = self.si
    new_si = TcStateIndex.from_config(self.config, mode=new_mode)
    # 保留 INS 部分 (pos/vel/att/bias/可选块)
    new_x = np.zeros(new_si.dim)
    new_P = np.zeros((new_si.dim, new_si.dim))
    # 复制 INS 固定 15 维 + 可选块 (索引在 old_si 和 new_si 中一致)
    ins_dim = 15 + sum([
        3 if old_si.has_lever_arm() else 0,
        2 if old_si.has_imu_angle() else 0,
        3 if old_si.has_imu_leverarm() else 0,
        1 if old_si.has_time_sync() else 0,
    ])
    new_x[:ins_dim] = self.x[:ins_dim]
    new_P[:ins_dim, :ins_dim] = self.P[:ins_dim, :ins_dim]
    # 新模式的 GNSS 参数块初始化
    if new_si.has_clk_bias():
        new_P[new_si.clk_bias, new_si.clk_bias] = 100.0**2
        # ... 其他钟差项
    if new_si.has_ambiguity():
        # 模糊度由 TcAmbiguity 重新初始化
        pass
    self.si = new_si
    self.x = new_x
    self.P = new_P
    self.mode = new_mode
    self._measurement_builder = measurement_builder
```

## 17. 残差输出接口与抗差估计预留

### 17.1 设计目标

主滤波（松组合 `LcEstimator` / 紧组合 `TcEstimator`）每次量测更新都提供完整的先验残差（新息向量 `v`、设计矩阵 `H`、噪声协方差 `R`、先验协方差 `P`）与后验残差快照，供：
- **在线监测**：残差大小反映量测质量与滤波器健康度
- **抗差估计**（`src/core/robust/`，当前预留不执行）：基于先验残差构造权函数调整 `R`
- **离线分析**：残差时序用于调参（如 `thresar1`、`maxinno`）

### 17.2 TcResiduals 类设计

```python
# src/core/tc/tc_residuals.py
import numpy as np
from dataclasses import dataclass, field
from typing import Optional
import logging

logger = logging.getLogger(__name__)


@dataclass
class ResidualSnapshot:
    """单次量测更新的残差快照。"""
    timestamp: float                        # 量测时间戳
    source: str                             # "gnss" / "nhc" / "zupt" / "zaru"
    # 先验 (更新前)
    v_prior: np.ndarray                     # 先验残差/新息 (n_obs,)
    H: np.ndarray                           # 设计矩阵 (n_obs, dim)
    R: np.ndarray                           # 量测噪声协方差 (n_obs, n_obs)
    P_prior: np.ndarray                     # 先验状态协方差 (dim, dim)
    x_prior: np.ndarray                     # 先验误差状态 (dim,)
    # 后验 (更新后)
    v_posterior: np.ndarray                 # 后验残差 (n_obs,)
    P_posterior: np.ndarray                 # 后验状态协方差 (dim, dim)
    x_posterior: np.ndarray                 # 后验误差状态 (dim,)
    # 抗差调整记录 (若启用)
    R_original: Optional[np.ndarray] = None # 抗差调整前的原始 R
    R_adjusted: Optional[np.ndarray] = None # 抗差调整后的 R (等于实际使用的 R)
    # 元信息
    info: dict = field(default_factory=dict)  # 卫星数/az/el/quality 等


class TcResiduals:
    """残差输出接口。

    参考:
      - GREAT-MSF _filter->update 内部残差导出
      - GINav ddres_rtkins 的 IGG-3 段 (残差标准化用于权函数)

    职责:
      - 记录每次 tc_meas_update 的先验/后验残差快照
      - 提供查询接口 (最近一次/历史时序/按来源过滤)
      - 提供抗差调整记录接口 (供 src/core/robust/ 使用)
      - 可选写入文件 (debug 用)
    """

    def __init__(self, config: dict):
        tc_cfg = config.get("tc", {})
        residuals_cfg = tc_cfg.get("residuals", {})
        # 是否启用残差记录 (默认启用, 开销小)
        self.enabled = residuals_cfg.get("enabled", True)
        # 历史快照最大保留数 (FIFO, 避免内存膨胀)
        self.max_history = residuals_cfg.get("max_history", 1000)
        # 是否写入文件
        self.dump_to_file = residuals_cfg.get("dump_to_file", False)
        self.dump_path = residuals_cfg.get("dump_path", None)
        # 历史快照 (按来源分组)
        self._history: dict[str, list[ResidualSnapshot]] = {}
        # 最近一次快照 (快速访问)
        self._latest: Optional[ResidualSnapshot] = None

    def record_prior(self, source: str, v_prior, H, R, P_prior, x_prior,
                     timestamp: Optional[float] = None, info: Optional[dict] = None) -> None:
        """记录先验残差 (更新前调用)。

        配合 record_posterior 完成一次快照。两次调用之间不应有其他量测更新。
        """
        if not self.enabled:
            return
        snap = ResidualSnapshot(
            timestamp=timestamp or 0.0,
            source=source,
            v_prior=np.asarray(v_prior).copy(),
            H=np.asarray(H).copy(),
            R=np.asarray(R).copy(),
            P_prior=np.asarray(P_prior).copy(),
            x_prior=np.asarray(x_prior).copy(),
            # 后验字段待 record_posterior 填充
            v_posterior=np.array([]),
            P_posterior=np.array([]),
            x_posterior=np.array([]),
            info=info or {},
        )
        self._latest = snap

    def record_posterior(self, source: str, v_posterior, P_posterior, x_posterior,
                         timestamp: Optional[float] = None) -> None:
        """记录后验残差 (更新后调用)。"""
        if not self.enabled or self._latest is None:
            return
        self._latest.v_posterior = np.asarray(v_posterior).copy()
        self._latest.P_posterior = np.asarray(P_posterior).copy()
        self._latest.x_posterior = np.asarray(x_posterior).copy()
        if timestamp is not None:
            self._latest.timestamp = timestamp
        # 入历史
        self._history.setdefault(source, []).append(self._latest)
        # FIFO 截断
        if len(self._history[source]) > self.max_history:
            self._history[source].pop(0)
        # 可选写文件
        if self.dump_to_file and self.dump_path:
            self._dump(self._latest)

    def record_robust_adjustment(self, source: str, R_original, R_adjusted) -> None:
        """记录抗差估计对 R 的调整 (预留, 当前不调用)。"""
        if not self.enabled or self._latest is None:
            return
        self._latest.R_original = np.asarray(R_original).copy()
        self._latest.R_adjusted = np.asarray(R_adjusted).copy()

    def latest(self) -> Optional[ResidualSnapshot]:
        """获取最近一次残差快照。"""
        return self._latest

    def history(self, source: Optional[str] = None) -> list[ResidualSnapshot]:
        """获取历史残差快照 (可按来源过滤)。"""
        if source is None:
            all_snaps = []
            for snaps in self._history.values():
                all_snaps.extend(snaps)
            return all_snaps
        return self._history.get(source, [])

    def _dump(self, snap: ResidualSnapshot) -> None:
        """将快照追加写入文件 (debug 用)。"""
        # 实现略: 写 v_prior/v_posterior/H/R/P 到 npz 或 csv
        pass
```

### 17.4 数据流

```
每次 tc_meas_update(v, H, R, source):
  ┌─────────────────────────────────────────────────┐
  │ 1. TcResiduals.record_prior(v, H, R, P_prior)  │  先验快照
  │ 2. [预留] RobustEstimator.adjust_R(v, H, R, P) │  抗差调整 (当前跳过, 见 robust.md)
  │ 3. joseph_update(v, H, R_used)                 │  量测更新
  │ 4. v_post = v - H·dx                           │  后验残差计算
  │ 5. TcResiduals.record_posterior(v_post, P)     │  后验快照
  └─────────────────────────────────────────────────┘
        │
        ├──→ self._latest (在线监测)
        ├──→ self._history (历史时序, 抗差估计输入)
        └──→ [可选] dump_to_file (离线分析)
```
